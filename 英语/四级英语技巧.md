📖 攻克“15选十”（选词填空）



这个题型考查的重点不是通篇理解，而是语法结构和词汇的快速应用。可以把它看作一个“逻辑填空游戏”，遵循以下步骤能极大提高效率和准确率：



第一步：标词性，而非看文章

先别急着读文章！你的首要任务是把给出的15个选项按照名词（n）、动词（v）、形容词（a）、副词（ad） 进行词性分类。这是最关键的一步，能立即缩小选择范围。判断词性可以借助常见的词缀，比如：



名词后缀：-tion, -sion, -ness, -ment, -er, -or, -ist等。



动词后缀：-ate, -ize, -ing, -ed等。



形容词后缀：-able, -al, -ant, -ent, -tive, -sive, -ous, -less等。



副词后缀：-ly, -ward, -wise等。

第二步：判空格，定所需词性

开始快速浏览文章，遇到空格时，根据其前后的语法结构，迅速判断此处需要什么词性的单词。以下是一些常见情况：



空格前有冠词（a/an/the），或后有动词，大概率缺名词。



空格前是名词/代词，后也是名词/代词，中间缺及物动词。



空格前是名词/代词，后是副词/介词，可能缺不及物动词。



空格后是名词，或前是be动词（is/am/are等），大概率缺形容词。



空格前后句子结构完整（主谓宾齐全），很可能是用副词来修饰动词或整个句子。



第三步：巧匹配，结合上下文

确定了空格的词性后，你的选择范围就从15选1变成了3选1甚至2选1。这时再根据空格所在句子的意思，从符合词性的少数几个选项中挑选出意思和逻辑最通顺的那一个。



这个题型的目标是在短时间内拿到尽可能多的分，如果遇到极难确定的空，可以先标记跳过，最后利用排除法来解决

🔍 阅读理解B部分：长篇阅读（信息匹配）



这个部分文章很长，但绝对不需要逐字逐句精读。它的核心是 “快速查找信息” ，就像玩“连连看”或“捉迷藏”。

先题后文，划关键词：千万不要先读文章！直接看后面的10个句子，并快速划出每句的关键词。关键词通常是：



显眼的名词：如人名、地名、组织名、专业术语等大写词。



数字、时间、百分比。



生僻词或核心动词/形容词词组



带着关键词，扫读文章：快速扫描文章，重点阅读首尾句和各段的小标题（如果有），大致了解文章结构和每段主旨。然后，利用你划出的关键词，像雷达一样在段落中扫描定位。特别注意文中的逻辑路标词，如表示转折（but, however）、因果（because, therefore）、目的（in order to）等关系的词，其后往往是重要信息点。



“所见即所得”与同义转述：正确答案往往是对原文信息的同义转述（换一种说法表达相同意思），而不是原词照搬。当你找到疑似出处时，仔细比对，看选项句子是否是对该段落内容的概括或改写

| 技巧类别 | 具体方法 | 说明与示例 |
| --- | --- | --- |
| 高效读题 | 寻找“定位词” | 优先选择拼写较长、生僻的低频词（如“internship”）、数字、百分比、年代（如“3.9 percent”）、专有名词（如人名“UNESCO”、地名）、合成词/固定概念（如“one-child”）。避免使用文章主题词（如文章通篇在讲“Venice”，这个词就无定位价值）。23 |
| | 识别同义替换 | 正确答案往往是对原文信息的同义转述。例如，题干中是“a series of books, mostly authored by Americans, warned...”，原文可能是“A succession of books, mainly by Americans... sounded the alarm”。其中“mostly”替换“mainly”，“warned”替换“sounded the alarm”。14 |
| 高效读文章 | 关注首尾句 | 段落的主旨句常出现在段落的开头第一句、第二句或最后一句，是高频出题点。15 |
| | 抓住逻辑路标词 | 转折词后（如but, however）、因果词（because, therefore）、结论建议词（conclusion, suggestion）等之后，常跟随着重要信息。15 |
| 答题策略 | 先易后难 | 先处理带有明显定位词（如数字、人名）的简单题目，再做需要深度理解的难题。对于耗时过长的题目，要果断跳过，保证整体正确率。2 |
| | “打包”处理乱序 | 由于题目顺序与文章段落顺序不一致，建议一次性记住所有题干的关键词和大意，然后浏览全文，争取读一遍文章解决多道题。3 |
