:: 的格式：类名::静态方法名、类名::实例方法名、对象::实例方法名、类名或接口名::普通或静态方法名、`类名::new` 构造器。



`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">String::length</font>`<font style="color:rgb(15, 17, 21);"> 属于“类名::实例方法”，但流中元素会作为调用者，比如 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">map(String::length)</font>`<font style="color:rgb(15, 17, 21);">，元素是 String，直接调用它的 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">length()</font>`





```plain
List<String> names = Arrays.asList("alice", "bob");

// 遍历打印
names.forEach(s -> System.out.println(s));
```

```plain
names.forEach(System.out::println);
```

方法引用最终还是会被编译器转换成 Lambda 表达式，进而创建一个函数式接口的实例。你并没有“不创建对象”，只是代码看起来像是直接用了方法。底层还是创建了接口实现对象，只不过你不用手写。它与lambda表达式最大的区别就是他简化了代码



总结

方法引用是 Lambda 的简写，当 Lambda 体只是调用一个已存在的方法且参数和返回值完全匹配时可以用。
