**<font style="color:rgb(15, 17, 21);">JVM 自动抛出：</font>**

+ <font style="color:rgb(15, 17, 21);">JVM 执行代码时，遇到非法操作（除以0、数组越界、空指针等），会</font>**<font style="color:rgb(15, 17, 21);">自动创建一个对应的异常对象并抛出</font>**<font style="color:rgb(15, 17, 21);">，不需要你写 throw。</font>
+ <font style="color:rgb(15, 17, 21);">如果没人 catch，JVM 调用</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">printStackTrace()</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">打印错误并终止程序。</font>

**<font style="color:rgb(15, 17, 21);">手动</font>****<font style="color:rgb(15, 17, 21);"> </font>**`**<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">throw</font>**`**<font style="color:rgb(15, 17, 21);">：</font>**

+ <font style="color:rgb(15, 17, 21);">程序员在代码里主动</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">new</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">一个异常对象，然后 throw 出去。</font>
+ <font style="color:rgb(15, 17, 21);">用于 JVM 无法自动判断的业务错误，比如“年龄不能为负”、“用户名已存在”。</font>
+ **<font style="color:rgb(15, 17, 21);">注意：</font>**<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">throw 抛出异常后，方法中断，后面的代码不执行。如果没有 catch，程序终止。</font>

**<font style="color:rgb(15, 17, 21);">什么时候必须手动 throw？</font>**<font style="color:rgb(15, 17, 21);">  
</font><font style="color:rgb(15, 17, 21);">当你想抛出的不是 JVM 能自动检测的运行时错误，而是业务规则错误时。比如：</font>

```java
if (age < 0) {
    throw new IllegalArgumentException("年龄不能为负数");
}
```

<font style="color:rgb(15, 17, 21);">JVM 不知道“年龄不能为负”是错误，只有你自己判断后主动抛。</font>
