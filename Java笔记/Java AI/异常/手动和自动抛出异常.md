**JVM 自动抛出：**

+ JVM 执行代码时，遇到非法操作（除以0、数组越界、空指针等），会**自动创建一个对应的异常对象并抛出**，不需要你写 throw。
+ 如果没人 catch，JVM 调用 `printStackTrace()` 打印错误并终止程序。

**手动**** **`**throw**`**：**

+ 程序员在代码里主动 `new` 一个异常对象，然后 throw 出去。
+ 用于 JVM 无法自动判断的业务错误，比如“年龄不能为负”、“用户名已存在”。
+ **注意：** throw 抛出异常后，方法中断，后面的代码不执行。如果没有 catch，程序终止。

**什么时候必须手动 throw？**  
当你想抛出的不是 JVM 能自动检测的运行时错误，而是业务规则错误时。比如：

```java
if (age < 0) {
    throw new IllegalArgumentException("年龄不能为负数");
}
```

JVM 不知道“年龄不能为负”是错误，只有你自己判断后主动抛。
