### 一、try-catch 完整结构：程序出错后怎么走？
**核心规则：**

+ `try` 里放可能出错的代码；一旦出错，程序**立刻跳转到 catch**，try 里剩余代码不再执行。
+ `catch` 接住错误并处理。
+ `finally` 不管有没有错**都会执行**。
+ catch 处理完后，继续执行 try-catch 结构**外面的代码**；如果没有 catch，程序直接死掉。

```java
public class ExceptionDemo1 {
    public static void main(String[] args) {
        System.out.println("程序开始");

        try {
            int result = 10 / 0;              // 抛出 ArithmeticException
            System.out.println("这行不会执行");  // 被跳过
        } catch (Exception e) {
            System.out.println("出错了：" + e.getMessage());  // 执行
        } finally {
            System.out.println("finally 执行");               // 一定执行
        }

        System.out.println("程序结束");        // 继续执行
    }
}
```

```java
程序开始
出错了：/ by zero
finally 执行
程序结束
```

**finally 的作用：** 常用于释放资源，比如关闭文件、关闭数据库连接、释放锁等。即使 try 或 catch 里有 return，finally 也会执行（极少数情况除外）。
