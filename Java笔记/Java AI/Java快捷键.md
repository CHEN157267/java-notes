Alt+回车：修改当前错误

Alt+P：强制让ai生成代码

遍历数组快速生成方式：数组名.for i

同时选择多行同一段文字：按住Alt选择

自动生成左边：control+Alt+v

Alt+insert：快速生成get，set方法，构造方法，重写方法

Alt+回车：IDEA自动修复代码中的bug

选中变量，shift+F6：批量修改

选中代码段，control + alt + t：选择东西进行包裹，可以选择循环

按住control不松，左键方法名：直接跳转到方法的地方

control+F12：显示这个项目的所有方法
