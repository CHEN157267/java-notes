对象的个数要求是有限个的时候，使用枚举

枚举项就是枚举类的对象，枚举项是提前创建好的

枚举项写法就是名字（成员变量），…；

构造方法应该用pravate，枚举类的构造方法默认就是private，不写也会默认加上，而且不需要空参构造，不需要set方法

枚举项其实是常量，所有的枚举项默认是public static final去修饰的不写也会默认加上

枚举项在运行enum的时候，会通过构造方法将枚举项全部创建出来，方便以后使用





```java
# Java枚举总结

## 核心特性：
1. **枚举项必须写在最前面**，用逗号分隔，最后用分号结束
2. **构造方法必须是private**（不写默认也是private）
3. **通常不需要set方法**，因为枚举应该是不可变的
4. **通常需要get方法**来访问私有成员
5. **成员变量通常用private final**，确保不可变性

## 特殊情况和注意事项：
6. **特殊场景下可以不用final**，如计数器、缓存等可变状态
7. **设计哲学**：Java相信程序员，给予更大灵活性
8. **继承限制**：枚举隐式final，不能被继承，但**可以实现接口**
9. **构造方法特色**：
   - 可以有**多个构造方法**
   - 不同的枚举项可以调用不同的构造方法
   - **空参构造可用来给多个枚举项提供相同的默认值**

## 重要限制：
10. **构造方法中不能用this()调用其他构造方法**（枚举不支持构造方法链式调用）
11. **构造方法中不能显式调用super()**（会隐式调用父类Enum的构造方法）
12. **不能使用super引用父类方法**（但可以重写父类方法）
```
