<font style="color:rgba(0, 0, 0, 0.85);">爬取除了版本号为 8,11,17 的 Java 文本。</font>

+ **<font style="color:rgb(0, 0, 0) !important;">正则表达式</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">：</font>`<font style="color:rgb(0, 0, 0);">((?i)Java)(?!8|11|17)</font>`
+ **<font style="color:rgb(0, 0, 0) !important;">解释</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">：利用负向先行断言 </font>`<font style="color:rgb(0, 0, 0);">(?!8|11|17)</font>`<font style="color:rgba(0, 0, 0, 0.85) !important;"> ，筛选出 </font>`<font style="color:rgb(0, 0, 0);">Java</font>`<font style="color:rgba(0, 0, 0, 0.85) !important;"> 后面不是指定版本号的文本，实现排除特定版本号的匹配需求。</font>
