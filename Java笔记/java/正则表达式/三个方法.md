### <font style="color:rgb(0, 0, 0);">1. </font>`<font style="color:rgb(0, 0, 0);">public boolean matches(String regex)</font>`
**<font style="color:rgb(0, 0, 0) !important;">功能</font>**<font style="color:rgba(0, 0, 0, 0.85);">：判断整个字符串是否完全匹配给定的正则表达式，只有字符串的全部内容都符合正则表达式定义的模式时，才返回</font>`<font style="color:rgba(0, 0, 0, 0.85);">true</font>`<font style="color:rgba(0, 0, 0, 0.85);"> ，否则返回</font>`<font style="color:rgba(0, 0, 0, 0.85);">false</font>`<font style="color:rgba(0, 0, 0, 0.85);"> 。</font>

```java
public class Main {
    public static void main(String[] args) {
        String email = "example@example.com";
        // 简单的邮箱正则表达式，实际应用中可更复杂精确
        String emailRegex = "^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\\.[A-Za-z]{2,}$"; 
        boolean isValid = email.matches(emailRegex);
        if (isValid) {
            System.out.println(email + " 是一个有效的电子邮件地址");
        } else {
            System.out.println(email + " 不是一个有效的电子邮件地址");
        }
    }
}
```





### <font style="color:rgb(0, 0, 0);">2. </font>`<font style="color:rgb(0, 0, 0);">public String replaceAll(String regex, String newStr)</font>`
**<font style="color:rgb(0, 0, 0) !important;">功能</font>**<font style="color:rgba(0, 0, 0, 0.85);">：按照给定的正则表达式查找字符串中所有匹配的子串，然后将这些匹配子串全部替换为指定的新字符串</font>`<font style="color:rgba(0, 0, 0, 0.85);">newStr</font>`<font style="color:rgba(0, 0, 0, 0.85);"> 。</font>

```java
public class Main {
    public static void main(String[] args) {
        String str = "hello123world456";
        // 将字符串中的数字替换为星号
        String result = str.replaceAll("\\d+", "*"); 
        System.out.println(result); // 输出：hello*world*
    }
}
```





### <font style="color:rgb(0, 0, 0);">3. </font>`<font style="color:#DF2A3F;">public String[] split(String regex)</font>`
**<font style="color:rgb(0, 0, 0) !important;">功能</font>**<font style="color:rgba(0, 0, 0, 0.85);">：根据给定的正则表达式作为分隔符，将字符串切割成多个子字符串，并以字符串数组的形式返回。</font>

```java
public class Main {
    public static void main(String[] args) {
        String str = "apple,banana;cherry";
        // 以逗号或分号作为分隔符切割字符串
        String[] result = str.split("[,;]"); 
        for (String s : result) {
            System.out.println(s); 
        } 
        // 输出：
        // apple
        // banana
        // cherry
    }
}
```
