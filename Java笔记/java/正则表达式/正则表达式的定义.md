#### <font style="color:rgb(0, 0, 0);">（1）</font>**<font style="color:rgb(0, 0, 0) !important;">直接定义字符串模式</font>**
```java
String regex = "\\d+"; // 匹配一个或多个数字
```

+ **<font style="color:rgb(0, 0, 0) !important;">注意</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">：Java 字符串中反斜杠</font>`<font style="color:rgb(0, 0, 0);">\</font>`<font style="color:rgba(0, 0, 0, 0.85) !important;">需要转义为</font>`<font style="color:rgb(0, 0, 0);">\\</font>`<font style="color:rgba(0, 0, 0, 0.85) !important;">。</font>

<font style="color:rgba(0, 0, 0, 0.85) !important;"></font>

#### <font style="color:rgb(0, 0, 0);">（2）</font>**<font style="color:rgb(0, 0, 0) !important;">使用预编译的 Pattern 对象（更高效）</font>**
```java
import java.util.regex.*;

// 编译正则表达式
Pattern pattern = Pattern.compile("\\d+");

// 创建Matcher对象用于匹配
Matcher matcher = pattern.matcher("abc123def");

// 执行匹配
boolean isMatch = matcher.find(); // true
```
