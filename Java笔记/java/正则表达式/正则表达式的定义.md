#### （1）**直接定义字符串模式**
```java
String regex = "\\d+"; // 匹配一个或多个数字
```

+ **注意**：Java 字符串中反斜杠`\`需要转义为`\\`。



#### （2）**使用预编译的 Pattern 对象（更高效）**
```java
import java.util.regex.*;

// 编译正则表达式
Pattern pattern = Pattern.compile("\\d+");

// 创建Matcher对象用于匹配
Matcher matcher = pattern.matcher("abc123def");

// 执行匹配
boolean isMatch = matcher.find(); // true
```
