| 特性 | 小驼峰命名法 | 大驼峰命名法 |
| --- | --- | --- |
| 首字母规则 | 首单词全小写，后续单词首字母大写 | 所有单词首字母均大写 |
| 常见用途 | 变量、方法、私有成员 | 类、接口、结构体、公开类型 |
| 别名 | lower camel case | Pascal Case / Upper camel case |
| 示例 |  userLoginCount  |  UserLoginCount  |
