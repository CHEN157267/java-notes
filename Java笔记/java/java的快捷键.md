control  + alt + l(代码对齐，但要防止与其他软件的快捷键冲突)；

快捷键：contrl + alt + t(在选中区域中生成循环）；

contrl + alt + v(自动生成左边）；

用鼠标点一下变量在alt+回车（将式子的左右两边分割开来）；

批量删除：按住ALT，鼠标左键选中 or 鼠标滚轮竖着选中；
