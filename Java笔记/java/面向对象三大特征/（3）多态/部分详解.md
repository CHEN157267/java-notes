#### （1）**成员变量不具备多态性**
+ **编译期绑定**：通过父类引用访问成员变量时，无论实际对象是子类还是父类，**变量值由引用类型决定**，而非实际对象类型

```java
class Parent {
    int num = 10;
}

class Child extends Parent {
    int num = 20;
}

// 测试
Parent p = new Child();
System.out.println(p.num); // 输出10（引用类型是Parent）
```



#### **转换前应使用 **`**instanceof**`** 检查**
```java
Parent p = new Child();
if (p instanceof Child) {
    Child c = (Child) p; // 安全转换
    c.childMethod();     // 调用子类特有方法
}
```







### 3. **<u>多态的适用范围</u>**
#### （1）**只适用于方法，不适用于静态方法、构造方法、私有方法**
+ **静态方法**：由类名直接调用，与实例无关。
+ **构造方法**：不能被继承，因此不存在重写。
+ **私有方法**：对子类不可见，无法重写。

#### （2）**final 方法不能被重写**
`final` 修饰的方法禁止子类重写，因此无法通过多态改变其行为。





**<u>总的来说，成员变量只是与引用类型有关，而引用类型是写在定义的对象前的那个，真正的多态是调用子类重写的对象和方法带参的多态</u>**
