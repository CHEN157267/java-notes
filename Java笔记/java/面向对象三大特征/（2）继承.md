构造方法的特点

<!-- 这是一张图片，ocr 内容为：继承中:构造方法的访问特点 父类中的构造方法不会被子类继承. 子类中所有的构造方法默认先访问父类中的无参构造,再执行自己. 为什么? 子类在初始化的时候,有可能会使用到父类中的数据,如果父类没有完成切始化,子类将无法使用父类的数据 子类初始化之前,一定要调用父类构造方法先完成父类数据空间的初始化. 怎么调用父类构造方法的? 子类构造方法的第一行语句默认都是:SUPER(),不写也存在,且必须在第一行. 如果想调用父类有参构造,必须手动写SUPER进行调用. -->
![](https://cdn.nlark.com/yuque/0/2025/png/52131016/1744252661326-c609537d-ee9d-456e-8fe3-58f47be654f9.png)

**<u>如果想调用父类有参构造，必须手动写super进行调用。</u>**

例:

```java
public class Parent {
    private int value;
    private String name;

    // 父类的有参构造方法
    public Parent(int value, String name) {
        this.value = value;
        this.name = name;
        System.out.println("父类构造方法被调用");
    }
}


public class Child extends Parent {
    public Child(int a, String b) {
        super(a, b); // 调用父类的构造方法，传递参数a和b
        System.out.println("子类构造方法被调用");
    }
}
```
