1、由于是protected修饰的，所以只能在同一个包下或者是其他包下的子类才能用，想要使用clone方法，只能自己去重写

2、在一个public的类中重写clone方法，还要让当前类实现Cloneable的接口，没有事其含义，只是为了提示此类一重写了Clone方法

3、在测试类使用Clone方法的时候需要强转



```java
 @Override
    protected Object clone() throws  CloneNotSupportedException{
        return super.clone();
    }

```
