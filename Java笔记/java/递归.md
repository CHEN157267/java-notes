对于一次能爬 1、2、3 个台阶的情况，递推关系应该是 `count(num) = count(num - 1) + count(num - 2) + count(num - 3)` ，因为最后一步爬 1 个台阶时，前面是 `num - 1` 个台阶的爬法；最后一步爬 2 个台阶时，前面是 `num - 2` 个台阶的爬法；最后一步爬 3 个台阶时，前面是 `num - 3` 个台阶的爬法。



当一次可以爬 `n` 个台阶时（这里 `n` 是最大步数，比如一次最多爬 3 个台阶，`n` 就是 3 ），递推关系需要把最后一步爬 1 个、2 个…… 直到 `n` 个台阶的情况都包含进来，也就是递归式要延伸到 `count(num - 1) + count(num - 2) + … + count(num - n)` 。
