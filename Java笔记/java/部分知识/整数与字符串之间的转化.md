**字符串转化成数字**

String str = "123";

**int num = Integer.parseInt(str);**



**数字转化为字符串**

（1）int num = 123; String str = num + ""; // 结果："123"

（2）int num = 123; String str = String.valueOf(num); // 结果："123"





### 总结
+ **日常简单转换**：优先使用 `String.valueOf()`，安全且性能好。
+ **格式化需求**：使用 `String.format()`。
+ **大量拼接**：使用 `StringBuilder`。
+ **快速写法**：直接加 `""` 适用于简单场景，但避免在循环中频繁使用。
