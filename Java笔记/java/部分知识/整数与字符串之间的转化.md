**<font style="color:#DF2A3F;">字符串转化成数字</font>**

String str = "123";

**int num = Integer.parseInt(str);**



**<font style="color:#DF2A3F;">数字转化为字符串</font>**

<font style="color:rgb(28, 31, 35);">（1）int num = 123; String str = num + ""; // 结果："123"</font>

（2）<font style="color:rgb(28, 31, 35);">int num = 123; String str = String.valueOf(num); // 结果："123"</font>

### <font style="color:#DF2A3F;">总结</font>
+ **<font style="color:rgb(0, 0, 0) !important;">日常简单转换</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">：优先使用</font><font style="color:rgba(0, 0, 0, 0.85) !important;"> </font>`<font style="color:rgb(0, 0, 0);">String.valueOf()</font>`<font style="color:rgba(0, 0, 0, 0.85) !important;">，安全且性能好。</font>
+ **<font style="color:rgb(0, 0, 0) !important;">格式化需求</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">：使用</font><font style="color:rgba(0, 0, 0, 0.85) !important;"> </font>`<font style="color:rgb(0, 0, 0);">String.format()</font>`<font style="color:rgba(0, 0, 0, 0.85) !important;">。</font>
+ **<font style="color:rgb(0, 0, 0) !important;">大量拼接</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">：使用</font><font style="color:rgba(0, 0, 0, 0.85) !important;"> </font>`<font style="color:rgb(0, 0, 0);">StringBuilder</font>`<font style="color:rgba(0, 0, 0, 0.85) !important;">。</font>
+ **<font style="color:rgb(0, 0, 0) !important;">快速写法</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">：直接加 </font>`<font style="color:rgb(0, 0, 0);">""</font>`<font style="color:rgba(0, 0, 0, 0.85) !important;"> 适用于简单场景，但避免在循环中频繁使用。</font>
