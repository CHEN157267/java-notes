### **公式总结**
设：

  


+ `arr` 是一维数组，长度为 `m`。
+ 目标二维数组为 `rows` 行 `cols` 列（即 `n = cols`）。

  


则必须满足：

+ `**m = rows × cols**`（元素总数匹配）。
+ **行索引**：`i / **<u>cols</u>**`。
+ **列索引**：`i % **<u>cols</u>**`。



**<u>前提是 m <= rows × cols</u>**
