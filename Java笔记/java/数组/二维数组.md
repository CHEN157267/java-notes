可通过手动输入来决定一位数组的长度，默认创建的一为数组长度是一样的

规则二维数组：若动态初始化时指定了列数（如 new int34 ），或静态初始化时每行元素数量相同，则所有一维数组长度一致。

不同:    int[][] arr = new int[2][];  // 动态创建2行，不指定列数  
arr[0] = new int[3];        // 第一行3列  
arr[1] = new int[5];        // 第二行5列



+ `arr[0]`代表第一行的数组引用，通过`new int[3]`为其分配长度为 3 的一维数组。
+ `arr[1]`代表第二行的数组引用，通过`new int[5]`为其分配长度为 5 的一维数组。







注意i/4 和i%4
