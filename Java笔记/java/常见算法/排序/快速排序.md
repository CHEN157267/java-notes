1，将0索引的书当作基准数

2，start是找比基准数要大的数，end是找比基准数要小的数然后进行交换

3，当start和end重合的时候所在位置就是基准数应存入的位置



end先移可以确保被换的数是小于基准数的



而start先移可能会导致当start和end重合的时候，被置换的数可能大于基准数
