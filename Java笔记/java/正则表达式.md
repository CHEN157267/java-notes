### `**\\.**`** 的含义**
+ **正则表达式层面****：**`**\.**`** ****表示匹配****字面意义的点号字符****（**`**.**`**）。**
+ **Java 字符串层面：由于反斜杠在字符串中需要转义，因此正则表达式的 **`**\.**`** 在 Java 字符串中需写作 **`**"\\."**`**。**



在正则表达式里，`.`有特殊含义，表示匹配除换行符之外的任意单个字符。如果想匹配普通的字符 “.” ，在正则表达式中要用`\.` 。但在 Java 字符串中表示这个正则表达式的`\.` ，就需要把其中的`\`转义，所以最终写成`\\.` 。
