### 用途
1. **初始化**：在编程中，有时需要先声明一个字符串变量，之后再对其赋值，这时可以将其初始化为空字符串。例如 `String str = "";` 。
2. **拼接操作起始值**：在字符串拼接场景中，可作为起始值。比如 `String result = "";` ，后续通过 `result = result + "新的内容";` 不断拼接新字符或字符串片段。
3. **表示特定状态**：在一些业务逻辑中，用来表示某种特定状态。比如在表单处理中，若某个文本框用户未输入任何内容，提交后对应接收的字符串可能就是空字符串，表示用户未提供相关信息 。

### 与其他概念区别
+ **和空格字符串的区别**：空格字符串是包含一个或多个空格字符（`' '` ）的字符串，如 `" "` 、 `" "` ，长度大于 0 ；而空字符串长度为 0 ，不包含任何字符。
+ **和**`**null**`**的区别**：`null` 不是一个对象实例，不能调用其方法，比如执行 `null.length()` 会报空指针异常；而空字符串是对象实例，可以调用其方法，如 `"" .length()` 返回 0 。
