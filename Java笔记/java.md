抽象类作为形参**完全支持多态**，通过子类继承和方法重写实现运行时动态绑定。其与接口多态的核心区别在于：

+ **抽象类**：强调整合（共享属性/逻辑），适合**同源子类**的扩展。
+ **接口**：强调行为契约，适合**跨体系功能组合**。

实际开发中，若子类有显著共性逻辑，优先用抽象类；若需解耦行为定义，或支持多重能力，则用接口。两者互补，共同构成 Java 多态的核心机制
