![](https://cdn.nlark.com/yuque/0/2025/png/52131016/1762862417475-812282e1-b67b-42e3-b677-7b5566606a5b.png)







```plain
<!DOCTYPE html>
<html>
<head>
    <title>target属性演示</title>
</head>
<body>
    <!-- 框架示例 -->
    <iframe name="contentFrame" width="400" height="200" src="about:blank"></iframe>
    <br>
    
    <!-- 各种target的链接 -->
    <a href="page1.html" target="_self">在当前窗口打开 (_self)</a><br>
    <a href="page2.html" target="_blank">在新窗口打开 (_blank)</a><br>
    <a href="page3.html" target="contentFrame">在框架中打开 (自定义名称)</a><br>
    <a href="https://www.example.com" target="_top">在顶级窗口打开 (_top)</a>
</body>
</html>

```



| target 值 | 作用 | 使用场景 |
| --- | --- | --- |
|  _blank  | 新窗口/新标签页 | 外部链接、不希望用户离开当前页面的链接 |
|  _self  | 当前窗口（默认） | 普通的页面内导航 |
|  _parent  | 父级框架 | 框架页面结构中的导航 |
|  _top  | 顶级窗口 | 跳出框架嵌套 |
|  框架名  | 指定框架 | 定向更新特定框架内容 |
