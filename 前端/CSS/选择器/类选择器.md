作用:查找标签，差异化设置标签的显示效果。

步骤:

定义类选择器 →.类名

使用类选择器 →标签添加 class="类名"

```html
.red{
color: red;
}
# 
<div class="red">这是 div 标签</div>
```



```html
.red {
color:口red;
}
.size {
font-size: 50px;
}
......
#用空格隔开；
<!--个标签可以使用多个类名，class属性值写多个类名，类名用空格隔开-->
<div class="red size">div 标签</div>
```
