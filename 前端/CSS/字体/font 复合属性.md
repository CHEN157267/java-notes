```html
div {
/*文字倾斜 */
font-style: italic;
/* 文字加朔*/
font-weight: 700;
/*字体大小是30px */
font-size:30px;
/*行高为字号的2倍 */
line-height:2;
/*字体是楷体 */
font-family:楷体;
}
```

```html
div f
/*font:是否倾斜 是否加粗 字号/行高 字体;*/
font:italic 700 30px/2 楷体;
```
