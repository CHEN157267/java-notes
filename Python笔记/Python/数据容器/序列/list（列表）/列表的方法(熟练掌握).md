（1）查询功能的方法

```java
mylist =["itcast","itheima","python"]
#1.1查找某元素在列表内的下标索引
index = mylist.index("itheima")
print(f"itheima在列表中的下标索引值是:{index}")
#1.2如果被查找的元素不存在，会报错
```

_**需要注意的事，index并非关键字**_



（2）插入语法（insert）

```java
#2:修改特定下标索引的值
mylist[0]="传智教育"
print(f"列表被修改元素值后，结果是:{mylist}")
#3:在指定下标位置插入新元素
mylist.insert(1，"best")
print(f"列表插入元素后，结果是:{mylist}")
```

_**列表的  insert()  方法在指定索引位置插入新元素时，原索引位置及其后续的所有元素会依次向后移动一位（即索引值增加 1），而不会被覆盖或删除。**_

```java

print(f"列表在追加了元素后，结果是:{mylist}")
```

（4）删除元素

[1]语法1: del 列表[下标]

```java
del mylist[2]
print(f"列表删除元素后结果是:{mylist}")
```

[2]语法2:列表.pop(下标)

```java
element = mylist.pop(2)
```

_**在 Python 列表的  pop()  方法中，返回的是被删除的数据本身（元素值），而不是其索引。**_
