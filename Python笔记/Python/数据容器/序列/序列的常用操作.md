包头不包尾，数字是索引



```java
#list进行切片操作，从1开始，4结束，步长1
my_list=[0，1，2，3，4，5，6]
result1 = my_list[1:4]
#对str进行切片，从头开始，到最后结束，步长2
my_str =“01234567"result3 = my_str[::2]
print(f"结果3:{result3}")
#对str进行切片，从头开始，到最后结束，步长-1
my_str ="01234567"
result4=my_str[::-1]
print(f"结果4:{result4}") #等同于将序列反转了
#对列表进行切片，从3开始，到1结束，步长-1
my_list=[0，1，2，3，4，5，6]
result5 = my_list[3:1:-1]
print(f"结果5:{result5}")
#对元组进行切片，从头开始，到尾结束，步长-2
my_tuple=(0，1，2，3，4，5，6)
result6 = my_tuple[::-2]
print(f"结果6:{result6}")
```



例题：取出黑马程序员

```java
my_str ="万过薪月，员序程马黑来，nohtyP学"
# 倒序字符串，切片取出
result1 =my_str[::-1][9:14]
print(f"方式1结果:{result1}")
#切片取出，然后倒序
result2 =my_str[5:10][::-1]
#切片取出，然后倒序
result2 = my_str[5:10][::-1]
print(f"方式2结果:{result2}")
# split分隔"，”replace替换"来"为空，倒序字符
result3 = my_str.split(",")[1].replace("来"，"")[::-1]
print(f"方式3结果:{result3}")
```

 str[::1]能完全打印的原因：

 str[::1]  会取到最后一个元素，因为它省略了 结束索引 ，默认会取完整个序列。

“包头不包尾”原则始终适用，但它限制的是指针在 结束索引 处停下，不取该索引的值。当 结束索引 被省略时，这个“尾”就是序列的边界之外，所以能取到实际的最后一个元素。
