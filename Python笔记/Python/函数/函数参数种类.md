使用方式上的不同，函数有4中常见参数使用方式:

位置参数

关键字参数

缺省参数

不定长参数



**Python函数参数知识点总结：**

1. **掌握位置参数**
    - 根据参数位置来传递参数
2. **掌握关键字参数**
    - 通过“键=值”形式传递参数，可以不限参数顺序
    - 可以和位置参数混用，位置参数需在前
3. **掌握缺省参数**
    - 不传递参数值时会使用默认的参数值
    - 默认值的参数必须定义在最后
4. **掌握不定长参数**
    - **位置不定长传递**：以`*`号标记一个形式参数，以**元组**的形式传入，形式参数一般命名为`args`
    - **关键字不定长传递**：以`**`号标记一个形式参数，以**字典**的形式传入，形式参数一般命名为`kwargs`
