1.构造方法的名称是:

init ，注意init前后的2个下划线符号

2.构造方法的作用:

构建类对象的时候会自动运行

构建类对象的传参会传递给构造方法，借此特性可以给成员变量赋值

3.注意事项:

构造方法不要忘记self关键字

在方法内使用成员变量需要使用self
