## 语雀同步脚本增量判断失灵（实测确认）
- 现象：小陈在语雀 Task12 笔记加了导语，连跑两次 sync_yuque_notes.py 都是「更新 0 / 没有变更，跳过提交」。
- 根因（实测）：`catalog_nodes` 接口返回的 195 个节点里 **0 个带 `updated_at` 字段**；脚本 `need = last_sync and node_dt and node_dt > last_sync`，字段缺失 → 永远为假 → 所有已存在文档一律 skip。与 Clash/代理无关（推送正常）。
- 绕过办法：直接调 `docs/{doc_id}/export`（force=1）拿最新正文，加 frontmatter 覆盖本地对应文件，再单独 git commit + push。已这样把 Task12 导语推上去（commit f346a2c）。
- 待办：**脚本本身尚未修复**。要彻底修，需换增量依据（如导出正文 hash 比对，或换带时间字段的语雀接口）。改之前跟小陈说一声。
