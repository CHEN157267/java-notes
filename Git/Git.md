+ **一个项目允许多个 **`**.gitignore**`：一层管一层，Git 原生支持。
+ `**.idea/**`** ****下的是 IDEA 自带**（自动生成，管它自己的临时文件），**根目录的是我写的**（管整个项目）。两者并存没问题，而且根目录那个已经把 `.idea/` 整体挡掉了，内层的其实都不会被上传。
