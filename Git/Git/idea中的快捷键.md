`**Ctrl+Shift+K**`** 选推送 → ****✅**** 完全正确**，但这个键有个前提：**必须先"提交"，再"推送"**。

日常更新代码的标准动作是**两步**：

| **步骤** | **快捷键** | **干什么** |
| --- | --- | --- |
| ① 提交 Commit | `Ctrl+K` | 把改动存进**你电脑上的** git 仓库（本地存档） |
| ② 推送 Push | `Ctrl+Shift+K` | 把本地存档**上传到 GitHub** |
