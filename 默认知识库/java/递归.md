<font style="color:rgba(0, 0, 0, 0.85);">对于一次能爬 1、2、3 个台阶的情况，递推关系应该是 </font>`<font style="color:rgba(0, 0, 0, 0.85);">count(num) = count(num - 1) + count(num - 2) + count(num - 3)</font>`<font style="color:rgba(0, 0, 0, 0.85);"> ，因为最后一步爬 1 个台阶时，前面是 </font>`<font style="color:rgba(0, 0, 0, 0.85);">num - 1</font>`<font style="color:rgba(0, 0, 0, 0.85);"> 个台阶的爬法；最后一步爬 2 个台阶时，前面是 </font>`<font style="color:rgba(0, 0, 0, 0.85);">num - 2</font>`<font style="color:rgba(0, 0, 0, 0.85);"> 个台阶的爬法；最后一步爬 3 个台阶时，前面是 </font>`<font style="color:rgba(0, 0, 0, 0.85);">num - 3</font>`<font style="color:rgba(0, 0, 0, 0.85);"> 个台阶的爬法。</font>

<font style="color:rgba(0, 0, 0, 0.85);"></font>

<font style="color:rgba(0, 0, 0, 0.85);">当一次可以爬 </font>`<font style="color:rgba(0, 0, 0, 0.85);">n</font>`<font style="color:rgba(0, 0, 0, 0.85);"> 个台阶时（这里 </font>`<font style="color:rgba(0, 0, 0, 0.85);">n</font>`<font style="color:rgba(0, 0, 0, 0.85);"> 是最大步数，比如一次最多爬 3 个台阶，</font>`<font style="color:rgba(0, 0, 0, 0.85);">n</font>`<font style="color:rgba(0, 0, 0, 0.85);"> 就是 3 ），递推关系需要把最后一步爬 1 个、2 个…… 直到 </font>`<font style="color:rgba(0, 0, 0, 0.85);">n</font>`<font style="color:rgba(0, 0, 0, 0.85);"> 个台阶的情况都包含进来，也就是递归式要延伸到 </font>`<font style="color:rgba(0, 0, 0, 0.85);">count(num - 1) + count(num - 2) + … + count(num - n)</font>`<font style="color:rgba(0, 0, 0, 0.85);"> 。</font>
