<font style="color:rgb(28, 31, 35);">接口的默认方法是能被实现类继承的，也能被重写，而接口的静态方法只能通过接口的名调用且不能被重写</font>

<font style="color:rgb(28, 31, 35);"></font>

<font style="color:rgb(28, 31, 35);"></font>

### <font style="color:rgb(0, 0, 0);"></font>**<font style="color:rgb(0, 0, 0) !important;">默认方法（Default Methods）</font>**
+ **<font style="color:rgb(0, 0, 0) !important;">可继承</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">：实现类会自动继承接口的默认方法，无需显式实现。</font>
+ **<font style="color:rgb(0, 0, 0) !important;">可重写</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">：实现类可以选择性重写默认方法，覆盖原实现。</font>
+ **<font style="color:rgb(0, 0, 0) !important;">调用方式</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">：通过实现类的实例调用。</font>

```java
interface MyInterface {
    default void defaultMethod() {
        System.out.println("接口的默认实现");
    }
}

class MyClass implements MyInterface {
    // 可选：重写默认方法
    @Override
    public void defaultMethod() {
        System.out.println("实现类重写的实现");
    }
}

// 使用
MyClass obj = new MyClass();
obj.defaultMethod(); // 输出：实现类重写的实现
```

<font style="color:rgba(0, 0, 0, 0.85) !important;"></font>

<font style="color:rgba(0, 0, 0, 0.85) !important;"></font>

### **<font style="color:rgb(0, 0, 0) !important;">静态方法（Static Methods）</font>**
+ **<font style="color:rgb(0, 0, 0) !important;">不可继承</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">：静态方法属于接口本身，实现类无法继承。</font>
+ **<font style="color:rgb(0, 0, 0) !important;">不可重写</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">：实现类不能重写接口的静态方法，即使定义同名方法也只是隐藏原方法。</font>
+ **<font style="color:rgb(0, 0, 0) !important;">调用方式</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">：只能通过接口名直接调用。</font>

```java
interface MyInterface {
    static void staticMethod() {
        System.out.println("接口的静态方法");
    }
}

class MyClass implements MyInterface {
    // 注意：这不是重写，只是定义了一个新的静态方法
    public static void staticMethod() {
        System.out.println("实现类的静态方法");
    }
}

// 使用
MyInterface.staticMethod(); // 输出：接口的静态方法
MyClass.staticMethod();     // 输出：实现类的静态方法（隐藏了接口的方法）
```
