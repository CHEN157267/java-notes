（2）构造代码块

写在成员位置，也就是在方法外，类里面，优先于空参构造和带参构造执行，只要调用构造方法就会执行代码块

目的：将多个构造方法中重复的代码提取出来

<!-- 这是一张图片，ocr 内容为：CLASS PUBLIC STUDENT{ STRING NAME; PRIVATE PRIVATE INT AGEJ 构造代码块 SYSTEM.OUT.PRINTLN("开始创建对象了"); PUBLIC STUDENT() 了 PUBLIC STUDENT(STRING NAME, INT AGE) { THIS.NAMENAME; THIS.AGE 三 AGEJ 了 -->
