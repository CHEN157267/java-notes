#### <font style="color:rgb(0, 0, 0);">（1）</font>**<font style="color:rgb(0, 0, 0) !important;">成员变量不具备多态性</font>**
+ **<font style="color:rgb(0, 0, 0) !important;">编译期绑定</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">：通过父类引用访问成员变量时，无论实际对象是子类还是父类，</font>**<font style="color:rgb(0, 0, 0) !important;">变量值由引用类型决定</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">，而非实际对象类型</font>

```java
class Parent {
    int num = 10;
}

class Child extends Parent {
    int num = 20;
}

// 测试
Parent p = new Child();
System.out.println(p.num); // 输出10（引用类型是Parent）
```



#### **<font style="color:rgb(0, 0, 0) !important;">转换前应使用 </font>**`**<font style="color:rgb(0, 0, 0);">instanceof</font>**`**<font style="color:rgb(0, 0, 0) !important;"> 检查</font>**
```java
Parent p = new Child();
if (p instanceof Child) {
    Child c = (Child) p; // 安全转换
    c.childMethod();     // 调用子类特有方法
}
```







### <font style="color:rgb(0, 0, 0);">3. </font>**<u><font style="color:#DF2A3F;">多态的适用范围</font></u>**
#### <font style="color:rgb(0, 0, 0);">（1）</font>**<font style="color:rgb(0, 0, 0) !important;">只适用于方法，不适用于静态方法、构造方法、私有方法</font>**
+ **<font style="color:rgb(0, 0, 0) !important;">静态方法</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">：由类名直接调用，与实例无关。</font>
+ **<font style="color:rgb(0, 0, 0) !important;">构造方法</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">：不能被继承，因此不存在重写。</font>
+ **<font style="color:rgb(0, 0, 0) !important;">私有方法</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">：对子类不可见，无法重写。</font>

#### <font style="color:rgb(0, 0, 0);">（2）</font>**<font style="color:rgb(0, 0, 0) !important;">final 方法不能被重写</font>**
`<font style="color:rgba(0, 0, 0, 0.85) !important;">final</font>`<font style="color:rgba(0, 0, 0, 0.85) !important;"> 修饰的方法禁止子类重写，因此无法通过多态改变其行为。</font>

<font style="color:rgba(0, 0, 0, 0.85) !important;"></font>



**<u><font style="color:rgb(28, 31, 35);">总的来说，成员变量只是与引用类型有关，而引用类型是写在定义的对象前的那个，真正的多态是调用子类重写的对象和方法带参的多态</font></u>**
