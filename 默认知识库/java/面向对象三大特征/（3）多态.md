用父调用找父，用子调用找子

+ **<font style="color:rgb(0, 0, 0) !important;">用父调用找父</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">：当使用父类引用指向子类对象，并且调用的是父类和子类都有的方法，但该方法在子类中没有被重写时，会调用父类的方法。</font>
+ **<font style="color:rgb(0, 0, 0) !important;">用子调用找子</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">：如果子类重写了父类的方法，使用父类引用指向子类对象调用该方法时，实际调用的是子类重写后的方法；而使用子类引用调用方法时，同样会调用子类自己的方法</font>
