<font style="color:rgba(0, 0, 0, 0.85);">贪婪匹配是正则表达式引擎的默认匹配模式，其核心逻辑是：</font>**<font style="color:rgb(0, 0, 0) !important;">在满足整体匹配的前提下，尽可能多地匹配重复的字符或分组</font>**<font style="color:rgba(0, 0, 0, 0.85);">。</font>

<font style="color:rgba(0, 0, 0, 0.85);"></font>

+ **<font style="color:rgb(0, 0, 0) !important;">触发条件</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">：当正则中包含</font><font style="color:rgba(0, 0, 0, 0.85) !important;"> </font>**<font style="color:rgb(0, 0, 0) !important;">量词（如</font>****<font style="color:rgb(0, 0, 0) !important;"> </font>**`**<font style="color:rgb(0, 0, 0);">*</font>**`**<font style="color:rgb(0, 0, 0) !important;">、</font>**`**<font style="color:rgb(0, 0, 0);">+</font>**`**<font style="color:rgb(0, 0, 0) !important;">、</font>**`**<font style="color:rgb(0, 0, 0);">?</font>**`**<font style="color:rgb(0, 0, 0) !important;">、</font>**`**<font style="color:rgb(0, 0, 0);">{n,m}</font>**`**<font style="color:rgb(0, 0, 0) !important;"> </font>****<font style="color:rgb(0, 0, 0) !important;">等）</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;"> </font><font style="color:rgba(0, 0, 0, 0.85) !important;">时，量词默认以贪婪模式工作。</font>
+ **<font style="color:rgb(0, 0, 0) !important;">关键逻辑</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">：引擎会先尝试匹配最多的字符，然后逐步回退（回溯），直到找到一个整体匹配的结果。</font>



1. **<font style="color:rgb(0, 0, 0) !important;">贪婪匹配的触发与量词直接相关</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">，而非 “与非贪婪条件对比”。</font>
