### **<font style="color:rgb(0, 0, 0) !important;">公式总结</font>**
<font style="color:rgba(0, 0, 0, 0.85) !important;">设：</font>

  


+ `<font style="color:rgb(0, 0, 0);">arr</font>`<font style="color:rgba(0, 0, 0, 0.85) !important;"> </font><font style="color:rgba(0, 0, 0, 0.85) !important;">是一维数组，长度为</font><font style="color:rgba(0, 0, 0, 0.85) !important;"> </font>`<font style="color:rgb(0, 0, 0);">m</font>`<font style="color:rgba(0, 0, 0, 0.85) !important;">。</font>
+ <font style="color:rgba(0, 0, 0, 0.85) !important;">目标二维数组为</font><font style="color:rgba(0, 0, 0, 0.85) !important;"> </font>`<font style="color:rgb(0, 0, 0);">rows</font>`<font style="color:rgba(0, 0, 0, 0.85) !important;"> </font><font style="color:rgba(0, 0, 0, 0.85) !important;">行</font><font style="color:rgba(0, 0, 0, 0.85) !important;"> </font>`<font style="color:rgb(0, 0, 0);">cols</font>`<font style="color:rgba(0, 0, 0, 0.85) !important;"> </font><font style="color:rgba(0, 0, 0, 0.85) !important;">列（即</font><font style="color:rgba(0, 0, 0, 0.85) !important;"> </font>`<font style="color:rgb(0, 0, 0);">n = cols</font>`<font style="color:rgba(0, 0, 0, 0.85) !important;">）。</font>

  


<font style="color:rgba(0, 0, 0, 0.85) !important;">则必须满足：</font>

+ `**<font style="color:rgb(0, 0, 0);">m = rows × cols</font>**`<font style="color:rgba(0, 0, 0, 0.85) !important;">（元素总数匹配）。</font>
+ **<font style="color:rgb(0, 0, 0) !important;">行索引</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">：</font>`<font style="color:rgb(0, 0, 0);">i / </font>**<u><font style="color:#DF2A3F;">cols</font></u>**`<font style="color:rgba(0, 0, 0, 0.85) !important;">。</font>
+ **<font style="color:rgb(0, 0, 0) !important;">列索引</font>**<font style="color:rgba(0, 0, 0, 0.85) !important;">：</font>`<font style="color:rgb(0, 0, 0);">i % </font>**<u><font style="color:#DF2A3F;">cols</font></u>**`<font style="color:rgba(0, 0, 0, 0.85) !important;">。</font>

<font style="color:rgba(0, 0, 0, 0.85) !important;"></font>

**<u><font style="color:#DF2A3F;">前提是 m <= rows × cols</font></u>**
