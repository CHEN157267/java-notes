用例：

```java
public class test {
    public static void main(String[] args) {
        char[] arr = new char[52]; // 小写+大写共52个字母
        
        // 生成小写字母 a-z (索引0-25)
        for (int i = 0; i < 26; i++) {
            arr[i] = (char) ('a' + i); // 动态计算每个小写字母
        }
        
        // 生成大写字母 A-Z (索引26-51)
        for (int i = 0; i < 26; i++) {
            arr[i + 26] = (char) ('A' + i); // 动态计算每个大写字母
        }
        
        // 输出数组中的所有字符
        for (int i = 0; i < arr.length; i++) {
            System.out.println(arr[i]);
        }
    }
}
```
