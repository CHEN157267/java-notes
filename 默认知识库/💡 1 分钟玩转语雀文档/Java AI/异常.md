### <font style="color:rgb(15, 17, 21);">一、try-catch 完整结构：程序出错后怎么走？</font>
**<font style="color:rgb(15, 17, 21);">核心规则：</font>**

+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">try</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">里放可能出错的代码；一旦出错，程序</font>**<font style="color:rgb(15, 17, 21);">立刻跳转到 catch</font>**<font style="color:rgb(15, 17, 21);">，try 里剩余代码不再执行。</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">catch</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">接住错误并处理。</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">finally</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">不管有没有错</font>**<font style="color:rgb(15, 17, 21);">都会执行</font>**<font style="color:rgb(15, 17, 21);">。</font>
+ <font style="color:rgb(15, 17, 21);">catch 处理完后，继续执行 try-catch 结构</font>**<font style="color:rgb(15, 17, 21);">外面的代码</font>**<font style="color:rgb(15, 17, 21);">；如果没有 catch，程序直接死掉。</font>

```java
public class ExceptionDemo1 {
    public static void main(String[] args) {
        System.out.println("程序开始");

        try {
            int result = 10 / 0;              // 抛出 ArithmeticException
            System.out.println("这行不会执行");  // 被跳过
        } catch (Exception e) {
            System.out.println("出错了：" + e.getMessage());  // 执行
        } finally {
            System.out.println("finally 执行");               // 一定执行
        }

        System.out.println("程序结束");        // 继续执行
    }
}
```

```java
程序开始
出错了：/ by zero
finally 执行
程序结束
```

**<font style="color:rgb(15, 17, 21);">finally 的作用：</font>**<font style="color:rgb(15, 17, 21);"> 常用于释放资源，比如关闭文件、关闭数据库连接、释放锁等。即使 try 或 catch 里有 return，finally 也会执行（极少数情况除外）。</font>
