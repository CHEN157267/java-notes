匿名内部类就是没有名字的内部类。它让你在创建对象的同时，直接定义类的实现，

而不需要单独写一个类文件。通常用来：

- 实现一个接口（只实现一次）

- 继承一个类（并重写方法）

- 简化代码，避免为了一次性使用而专门写一个具名类



语法：

new 接口名/类名() {

    // 实现或重写方法

};



如果继承一个类，且父类构造器需要参数，就在括号里传参：

new 父类名(参数) {

    // 重写方法

};



总结

- 匿名内部类：没有名字的内部类，用于快速创建一个类的实例。

- 语法：new 接口/类() { ... }

- 用途：临时实现接口、继承类、简化代码。

- 限制：无构造器、无静态成员（除了常量）、只能访问 effectively final 变量。

- 替代：函数式接口可以改用 Lambda 表达式。



疑问1：匿名内部类的花括号可不可以空着？

结论：可以，但没有实际意义。匿名内部类通常用来重写方法或实现接口，提供定制行为；

如果只是要一个类的实例，直接 new 类名() 就行，不必用匿名内部类。



疑问2：匿名内部类的位置？能不能“裸写”？

匿名内部类是一个表达式，可以出现在任何需要对象引用的地方：

- 赋值给变量：Runnable r = new Runnable() {...};

- 作为方法参数：addListener(new Listener() {...});

- 作为返回值：return new Interface() {...};

- 独立成句（裸写）：new Runnable() {...}; —— 语法合法，但对象无引用，通常无意义，不推荐。
