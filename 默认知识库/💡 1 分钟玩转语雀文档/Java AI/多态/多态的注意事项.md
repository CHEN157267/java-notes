# Java多态与类型转换总结

## 1. 对象多态（引用类型）

### 方法参数多态：
- 当形参是父类类型时，传入子类对象会自动向上转型
- 例如：`method(Fu f)` 传入 `Zi` 对象 → 自动：`Fu f = zi对象`

### 集合存储多态：
- 数组/集合声明为父类类型，可存储任何子类对象
- 例如：`List<Fu> list` 可添加 `new Zi1()`, `new Zi2()`

### 显式父类引用的优势：
- `Fu f = new Zi()` 创建"自由指针"
- 可随时改变指向不同子类：`f = new Zi1(); f = new Zi2();`
- 但只能调用父类声明的方法（实际执行子类重写版本）

## 2. 基本类型转换

### 与多态无关：
- `short`、`int`、`long`等基本类型**没有继承关系**
- 它们是原始数据类型，不是类

### 转换规则：
- 小范围 → 大范围：自动隐式转换
