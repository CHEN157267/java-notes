问题：已知向量组  α₁, α₂, α₃  和一个新向量  β ，问  β  能否由  α₁, α₂, α₃  线性表示？如果能，具体系数是多少？



方法：这就是在解一个非齐次线性方程组。设  x₁α₁ + x₂α₂ + x₃α₃ = β ，将向量作为列写成矩阵，通过行变换求解未知数  x₁, x₂, x₃ 。



结论：从图中结果  x₁=-11, x₂=14, x₃=9  可知， β  可以由  α₁, α₂, α₃  线性表示，表示为： β = -11α₁ + 14α₂ + 9α₃ 。





第二部分：引出的新问题（黑板下半部分）



在解决了上面那个具体问题后，老师很自然地提出了一个更本质的问题：



问题：那么，用来表示别人的这三个向量  α₁, α₂, α₃  它们自己，彼此之间是什么关系？它们是线性相关还是线性无关？



“谁和谁的线性相关？”：指的就是  α₁, α₂, α₃  这三个向量之间是否线性相关。



方法：要判断三个向量是否线性相关，就是看是否存在不全为零的系数  k₁, k₂, k₃ ，使得  k₁α₁ + k₂α₂ + k₃α₃ = 0 （零向量）。



这等价于解一个以这些向量为列构成的齐次方程组  A = (α₁, α₂, α₃) ，判断其秩  r(A) 。



判断条件（图中条件②有笔误，应为）：



线性相关 ⇔ 向量组的秩 小于 向量的个数（即  r(A) < 3 ）。这意味着至少有一个向量是“多余的”，可以被其他向量线性表示。



线性无关 ⇔ 向量组的秩 等于 向量的个数（即  r(A) = 3 ）。这意味着每一个向量都无法被其他向量表示，彼此独立。
