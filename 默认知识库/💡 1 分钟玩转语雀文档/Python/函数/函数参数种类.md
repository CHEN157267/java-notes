使用方式上的不同，函数有4中常见参数使用方式:

位置参数

关键字参数

缺省参数

不定长参数



**<font style="color:rgb(0, 0, 0);">Python函数参数知识点总结：</font>**

1. **<font style="color:rgb(0, 0, 0);">掌握位置参数</font>**
    - <font style="color:rgb(0, 0, 0);">根据参数位置来传递参数</font>
2. **<font style="color:rgb(0, 0, 0);">掌握关键字参数</font>**
    - <font style="color:rgb(0, 0, 0);">通过“键=值”形式传递参数，可以不限参数顺序</font>
    - <font style="color:rgb(0, 0, 0);">可以和位置参数混用，位置参数需在前</font>
3. **<font style="color:rgb(0, 0, 0);">掌握缺省参数</font>**
    - <font style="color:rgb(0, 0, 0);">不传递参数值时会使用默认的参数值</font>
    - <font style="color:rgb(0, 0, 0);">默认值的参数必须定义在最后</font>
4. **<font style="color:rgb(0, 0, 0);">掌握不定长参数</font>**
    - **<font style="color:rgb(0, 0, 0);">位置不定长传递</font>**<font style="color:rgb(0, 0, 0);">：以</font>`<font style="color:rgb(0, 0, 0);">*</font>`<font style="color:rgb(0, 0, 0);">号标记一个形式参数，以</font>**<font style="color:rgb(0, 0, 0);">元组</font>**<font style="color:rgb(0, 0, 0);">的形式传入，形式参数一般命名为</font>`<font style="color:rgb(0, 0, 0);">args</font>`
    - **<font style="color:rgb(0, 0, 0);">关键字不定长传递</font>**<font style="color:rgb(0, 0, 0);">：以</font>`<font style="color:rgb(0, 0, 0);">**</font>`<font style="color:rgb(0, 0, 0);">号标记一个形式参数，以</font>**<font style="color:rgb(0, 0, 0);">字典</font>**<font style="color:rgb(0, 0, 0);">的形式传入，形式参数一般命名为</font>`<font style="color:rgb(0, 0, 0);">kwargs</font>`
