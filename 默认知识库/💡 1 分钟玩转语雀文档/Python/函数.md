在python中的函数可以有多个返回值

```python
def test_return():
    return 1,2
x，y= test_return()
print(x) # 结果1
print(y) #结果2
```

按照返回值的顺序，写对应顺序的多个变量接收即可

变量之间用逗号隔开

支持不同类型的数据return
