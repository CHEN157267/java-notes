| 运算符 | 名称 | 描述 | 示例 | 返回值 |
| --- | --- | --- | --- | --- |
|  and  | 逻辑与 | 两边条件都为  True  时，结果才为  True  |  True and False  |  False  |
|  or  | 逻辑或 | 两边条件至少有一个为  True  时，结果就为  True  |  True or False  |  True  |
|  not  | 逻辑非 | 对条件进行取反， True  变  False ， False  变  True  |  not True  |  False  |
