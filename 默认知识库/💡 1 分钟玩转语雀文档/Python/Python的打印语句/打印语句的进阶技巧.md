 sep  参数：指定多个输出值之间的分隔符，默认为空格。

```plain
print("2023", "12", "31", sep="-")  # 输出：2023-12-31
print("Name", "Age", sep=": ")      # 输出：Name: Age

```



 end  参数：指定输出结尾的字符，默认为换行符  \n 。可以用来实现不换行输出。

```plain
print("Loading", end="... ")
print("Done!")  # 输出：Loading... Done!

```



 file  参数：将内容输出到文件，而不是默认的控制台。

```plain
with open("output.txt", "w") as f:
    print("This goes into the file.", file=f)

```



file的详解

```plain
# 1. 基本文件输出
with open('output.txt', 'w') as f:  # 以写入模式打开文件
    print('Hello, World!', file=f)  # 将内容输出到文件
# 文件会自动关闭，'Hello, World!' 已被写入 output.txt

# 2. 输出多项内容并自定义分隔符
name = 'Alice'
age = 25
with open('info.txt', 'w') as f:
    print(name, age, 'New York', sep='|', end='', file=f)  # 使用竖线分隔，结尾不换行
# 文件内容将是：Alice|25|New York

# 3. 追加模式（不覆盖原有内容）
with open('log.txt', 'a') as f:  # 以追加模式打开文件
    print('A new log entry.', file=f)

```



部分解析



相对路径：当只写文件名（如  'output.txt' ）时，这被称为相对路径。程序会从它的“当前工作目录”出发来定位这个文件。这个目录通常是运行Python脚本所在的文件夹。如果文件就在脚本旁边，用相对路径最简单。



理解  with open(...) as f 

这行代码是Python中安全处理文件的最佳方式，它利用了上下文管理器。

 open()  函数：它的作用是打开一个文件，并返回一个表示该文件的文件对象。

 as f ：关键字  as  将  open()  返回的文件对象赋值给变量  f 。这样，在接下来的代码块中，我们就可以通过变量  f  来操作这个文件了，比如读取内容或写入内容。



 print('Hello', file=f) ：

 print  函数默认将内容输出到屏幕（标准输出）。

 file=f  这个参数的作用是重定向。它告诉  print  函数：“不要把你后面的内容打印到屏幕上了，请把它们‘写’到我给你的这个‘文件遥控器’ f  所对应的文件里去。”
