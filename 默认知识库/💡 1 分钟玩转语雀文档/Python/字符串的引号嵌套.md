用例

```plain
sentence1 = "I can't wait to learn Python."
print(sentence1)  # 输出：I can't wait to learn Python.

sentence2 = 'The book is titled "Python Crash Course".'
print(sentence2)  # 输出：The book is titled "Python Crash Course".

```





```plain
sentence3 = 'I can\'t believe it\'s so easy!'
print(sentence3)  # 输出：I can't believe it's so easy!

sentence4 = "She said, \"It's a beautiful day.\""
print(sentence4)  # 输出：She said, "It's a beautiful day."

```



```plain
sentence5 = """The teacher said, "Please read the chapter titled 'Data Structures' for next class.""""
print(sentence5)
# 输出：The teacher said, "Please read the chapter titled 'Data Structures' for next class."

```
