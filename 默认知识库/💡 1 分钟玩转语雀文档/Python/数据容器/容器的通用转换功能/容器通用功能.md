会将数据变为list，且容器的排序结果进行反转

```python
my_list = [3, 1, 4, 2]

# 1. 默认排序（升序）
print(sorted(my_list))           # 输出：[1, 2, 3, 4]

# 2. 使用 reverse=True 参数（降序排序）
print(sorted(my_list, reverse=True))  # 输出：[4, 3, 2, 1]

# 3. 真正的反转方法：.reverse() （仅仅是颠倒顺序，不进行大小排序）
my_list.reverse() # 注意：.reverse() 方法直接修改原列表，不返回值
print(my_list)                   # 输出：[2, 4, 1, 3] （原始顺序是 [3, 1, 4, 2]）

```

当您使用  list(容器)  这类函数时，它的作用就是将一个其他类型的容器（或可迭代对象）转换成一个新的列表。

它会返回一个新对象：转换后得到的是一个全新的列表，原来的容器并不会被改变。
