pop方法：

你需要从一个集合中获取一个元素，并且不关心它具体是哪一个。

你确实打算将这个元素从集合中移除。

例如，模拟抽奖池，抽中的人不再参与后续抽取



```java
my_set = {"传智教育”,"黑马程序员"，"itheima"，"传智教育"，"黑马程序员"，"itheima"，"传智“，"黑马程序员"，"itheima"}
my_set_empty= set()
#定义空集合
print(f"my_set的内容是:{my_set}，类型是:{type(my_set)}")
print(f"my_set_empty的内容是:{my_set_empty}，类型是:{type(my_set_empty)}")
```



添加元素

```java
my_set.add("Python")

print(f"my_set添加元素后结果是:{my_set}")
```



消除2个集合的差集

语法:集合1.difference update(集合2)

功能:对比集合1和集合2，在集合1内，删除和集合2相同的元素，

结果:集合1被修改，集合2不变

```java
set1={1，2，3}十
set2={1，5，6}
set1.difference update(set2)
print(set1) # 结果:{2，3}
print(set2) # 结果:{1，5，6}
```
