层叠样式表 (Cascading Style sheets，缩写为 CS5)，是一种 样式表 语言，用来描述 HTML 文档的呈现(美化内容)。

书写位置:title 标签下方添加 style 双标签，style 标签里面书写 CSS 代码。



```html
<title>Css 初体验</title>
<style>
/* 选择器{}*/
p{
/* css 属性 */
color: red;
}
</style>
<p>体验 csS</p>
```



常规书写css顺序：盒子，文字，阴影圆角
