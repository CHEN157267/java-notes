div就像是一个盒子，无论大小多少，他都会独占n行

```html
<style>
.red {
/* 宽度 */
width: 100px;
  /*高度 */
  height: 100px;
  /*背景色 */
background-color: □brown;
.orange {
  width: 200px;
  height: 200px;
  background-color: brown;
}
</style>
</head>
<body>
<div class="red">div1</div>
  <div class="orange">div2</div>
```
