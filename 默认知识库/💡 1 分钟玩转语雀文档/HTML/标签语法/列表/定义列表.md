标签:dl嵌套 dt 和 dd，dl 是定义列表，dt 是定义列表的标题，dd 是定义列表的描述/详情。

<!-- 这是一张图片，ocr 内容为：<DL> <DT>列表标题</DT> <DD>列表描述/详情</DD> </P/> 注意事项: DL 里面只能包含DT和D DT和DD里面可以包含任何内容 -->
![](https://cdn.nlark.com/yuque/0/2025/png/52131016/1762862696821-8cabc675-266a-4f6c-9b2c-f1aebf87aafe.png)



```html
<!DOCTYPE html>
<html>
  <head>
    <style>
      /* 为整个定义列表设置边框，使其像一个表格容器 */
      dl {
        border: 1px solid #ccc; /* 列表外边框 */
        width: 100%; /* 宽度自适应容器 */
        max-width: 600px; /* 最大宽度限制 */
        border-collapse: collapse; /* 关键属性：合并相邻边框 */
        margin: 20px 0; /* 添加一些外边距 */
      }

      /* 为每个术语和描述设置边框，模拟表格行 */
      dt, dd {
        border: 1px solid #ccc; /* 为每个术语和描述设置边框 */
        padding: 8px 12px; /* 添加内边距，让内容不紧贴边框 */
        margin: 0; /* 移除默认的外边距，确保边框紧密连接 */
      }

      /* 设置术语的样式，可以像表头 */
      dt {
        background-color: #f5f5f5; /* 浅灰色背景，类似表头 */
        font-weight: bold;
        border-bottom: 2px solid #999; /* 底部边框加粗，增强行分隔感 */
        width: 30%; /* 可设置术语部分宽度，类似表格第一列 */
        float: left; /* 让术语和描述并排 */
        clear: left; /* 确保每个术语从新行开始 */
        box-sizing: border-box; /* 确保宽度计算包含内边距和边框 */
        height: 40px; /* 固定高度，对齐同行描述 */
        line-height: 24px; /* 行高，使文字垂直居中 */
      }

      /* 设置的描述样式，像表格单元格 */
      dd {
        background-color: #fff; /* 白色背景 */
        margin-left: 30%; /* 左边距等于术语的宽度，防止重叠 */
        box-sizing: border-box; /* 确保宽度计算包含内边距和边框 */
        min-height: 40px; /* 最小高度，确保即使内容为空也有视觉高度 */
        line-height: 24px; /* 行高，与术语对齐 */
      }
      /* 清除浮动，确保容器高度正常计算 */
      dl:after {
        content: "";
        display: table;
        clear: both;
      }
    </style>
  </head>
  <body>

    <dl>
      <dt>姓名</dt>
      <dd>张三</dd>

      <dt>电子邮箱</dt>
      <dd>zhangsan@example.com</dd>

      <dt>职业</dt>
      <dd>Web 前端开发工程师</dd>

      <dt>技能</dt>
      <dd>HTML, CSS, JavaScript</dd>
      <dd>响应式设计，用户体验优化</dd> <!-- 一个术语对应多个描述 -->
    </dl>

  </body>
</html>

```





定义列表（ <dl> ）的结构确实可以这样类比： <dt>  像是行的“标题”或“标签”，而紧随其后的一个或多个  <dd>  就是该标题对应的“数据”或“内容”。整个列表就是由这样一组组的“标题-数据”对构成的 。



定义列表是用dl将这个包裹起来，dt是那一行表格的开头提示词，紧跟在后面的dd就是这行dt的数据，那有多个数据，一个dt的后面跟着多个dd，这个表格就是这样一行行写的
