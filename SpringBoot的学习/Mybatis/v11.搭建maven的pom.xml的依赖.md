在mybatis中的占位符表示成＃{}，{}中填写的是替代的变量名



put是Map的“添加键值对”方法：

语法：map.put(键, 值);

```java
Map<String, Object> data = new HashMap<>(); // 创建一个Map，键是String，值是Object（啥都能存）
data.put("k1", "川A88888"); // 键是"k1"，值是"川A88888"
data.put("k2", "比亚迪汉"); // 键是"k2"，值是"比亚迪汉"
data.put("k3", 20.2);       // 键是"k3"，值是数字20.2
```

在MyBatis中，当你的SQL需要**动态参数**（比如插入一条车的信息，字段可能不固定），用`Map`传参很灵活：

+ 你不用定义一个`Car`类，直接把参数打包成`Map`，MyBatis会根据`Map`的**键（Key）**去匹配SQL里的`#{k1}`、`#{k2}`…
+ 类比：`Map`就像“快递包裹”，`k1`、`k2`是“收件人标签”，MyBatis会根据标签把包裹（值）送到正确的地方（SQL的参数位置）。

关于占位符

| **特性** | **MyBatis的**`**#{}**` | `**printf**`**的**`**%s**` |
| :--- | :--- | :--- |
| 作用 | SQL预编译（防止注入+类型安全） | 字符串格式化（拼接文本） |
| 原理 | 先编译SQL，再传参数（参数会被转义） | 直接替换占位符（字符串拼接） |
| 安全性 | 高（防止SQL注入） | 低（直接拼接，易被注入） |
| 类型处理 | 自动处理类型（如数字、日期） | 需手动指定类型（如`%d`数字、`%f`浮点） |


**SQL注入**：黑客通过**构造恶意参数**，篡改你的SQL语句，达到“偷数据”或“删库”的目的。



+ 举个例子：你的SQL是 `select * from user where username='${user}' and password='${pwd}'`（注意是`${}`，不是`#{}`）。如果黑客输入：`user=admin' --`，`pwd=123`，最终SQL会变成：

```plain
select * from user where username='admin' -- ' and password='123'
```

`--`是SQL的“注释符”，后面的条件被注释了，相当于**只校验用户名**，黑客就能免密登录！

+ **MyBatis的**`**#{}**`**能防注入**：因为`#{}`是**预编译**（先编译SQL，再传参数），参数会被当成“纯数据”，不会被当成SQL代码执行。
