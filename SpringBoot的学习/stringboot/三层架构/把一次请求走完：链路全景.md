```plain
客户端（IDEA HTTP Client / 浏览器 / Postman）
   ↓ TCP 连接（连不上会报 Connection refused）
Tomcat :8080                      ← Servlet 容器，负责监听端口、接住连接
   ↓
DispatcherServlet                 ← Spring MVC 的核心，是跑在 Tomcat 里的一个 servlet
   ├─ 参数绑定 + @Valid 校验        ← ★ 门口这道岗，不通过就到此为止
   ↓ 通过了才允许继续
Controller 方法体                  ← 我们的 switch / Result 在这里
   ↓
Service 层
   ↓
Mapper 层
   ↓
MySQL（端口 3307 / 库 demo_db / 表 user）
```

**关键点**：`@Valid` 不在 Controller **里面**，在 Controller **门口**。

校验失败时，后面的 `Controller 方法体 → Service → Mapper → DB`**一个都不会被碰到**。

所以"数据没进库"的准确含义是——**根本没走到那**，不是"写进去又回滚了"。
