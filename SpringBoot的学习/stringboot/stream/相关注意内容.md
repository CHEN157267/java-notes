<? super T> 的理解



对，你的理解正确。? super T 表示T 类型或者 T 的父类型。这么写是为了兼容性：比如你有一个能比较 Number 的 Comparator，那么它也能用来比较 Integer（因为 Integer 是 Number 的子类）。所以允许传入比较父类型的 Comparator 更灵活。不用太纠结，知道它是这个意思就行。



写在返回值类型前的＜T＞的理解

```plain
public static <T> T getFirst(List<T> list) {
    return list.get(0);
}
```

写在返回值类型前的 <T> 是一个类型参数的声明，它是一个占位符，告诉编译器“接下来的方法签名和方法体中出现的 T 都代表同一个类型”。但这个 T 具体是什么类型，要等调用方法时由传入的实际参数推断出来。所以 <T> 不是“声明形参的 T 的类型”，而是声明整个方法可以使用的类型变量。



<T> 就是一个类型占位符，表示“这里有一个类型，但是具体是什么类型，等调用方法的时候由传入的参数推断”。这样同一个方法可以处理不同类型的集合，兼容性更强。
