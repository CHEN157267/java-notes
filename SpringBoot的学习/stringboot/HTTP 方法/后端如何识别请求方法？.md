+ <font style="color:rgb(15, 17, 21);">HTTP 请求报文中包含一个“方法”字段，比如 GET、POST 等。</font>
+ <font style="color:rgb(15, 17, 21);">浏览器地址栏直接访问，默认发</font><font style="color:rgb(15, 17, 21);"> </font>**<font style="color:rgb(15, 17, 21);">GET</font>**<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">请求。</font>
+ <font style="color:rgb(15, 17, 21);">前端 JavaScript 发送请求时，可以指定方法，如：</font>

```java
fetch('/user', {
    method: 'POST',
    body: JSON.stringify({name: '张三'})
})
```

+ <font style="color:rgb(15, 17, 21);">后端根据 </font>**<font style="color:rgb(15, 17, 21);">URL + HTTP 方法</font>**<font style="color:rgb(15, 17, 21);"> 匹配对应的 Controller 方法，不需要猜测。</font>
