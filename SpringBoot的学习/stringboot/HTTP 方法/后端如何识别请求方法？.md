+ HTTP 请求报文中包含一个“方法”字段，比如 GET、POST 等。
+ 浏览器地址栏直接访问，默认发 **GET** 请求。
+ 前端 JavaScript 发送请求时，可以指定方法，如：

```java
fetch('/user', {
    method: 'POST',
    body: JSON.stringify({name: '张三'})
})
```

+ 后端根据 **URL + HTTP 方法** 匹配对应的 Controller 方法，不需要猜测。
