| 误区 | 正确理解 |
| --- | --- |
| `@RestController`<br/> 负责页面跳转 | 不负责，它接收请求并返回数据（JSON），页面跳转是前端的事 |
| `@RequestMapping`<br/> 是页面跳转 | 不，它只是定义“处理哪个 URL”，返回的是数据不是跳转 |
| Spring 类似于 JVM | 不，JVM 是底层运行环境，Spring 是跑在 JVM 上的框架 |
| `@Component`<br/> 是容器 | 不，它是标签，Spring 容器才是真正存放 Bean 的容器 |
| 控制器里所有方法都有 `@RequestMapping` | 不，内部辅助方法不需要 |
| 用 `@interface`<br/> 定义注解后就有功能 | 不，必须自己写处理逻辑才有功能 |
