| **接口** | **实现对象从哪来** | **例子** |
| --- | --- | --- |
| Service | **Spring 容器创建**（有 `@Service`<br/> 实现类） | `UserService` |
| Mapper | **MyBatis 动态代理生成** | `UserMapper` |
| **ChatClient** | **你自己 **`**builder.build()**`**造** | 这次这个 |


**共同点：都是"接口变量 → 某个实现对象"。区别只在"谁把对象给你"。** 你之前的经验里"给对象"的都是框架，这次是**你自己**，所以觉得怪 —— 但这在 Java 里天天发生（`List<String> list = new ArrayList<>()` 也是"接口变量装实现对象"）。
