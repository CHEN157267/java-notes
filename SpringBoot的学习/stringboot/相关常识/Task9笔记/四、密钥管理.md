### 2 为什么安全（两层）
| 层 | 保证 |
| --- | --- |
| ① **当前文件** | `.gitignore` 含 `.idea/` → Git **不跟踪**这个目录 |
| ② **历史** | 扫 `git log --all -p` → **20 个提交里从来没出现过 **`**.idea**`** 文件** |


**为什么第二层重要**：**"提交过再删掉"是删不干净的** —— 历史里还在。真正的安全是**从来没有提交过**。

（真实经历：java-notes 曾把名字提交上去，最后**删库重建**才解决。）

### 3 环境变量的名字和值，都不能有空格
+ **名字带尾随空格**（`'DEEPSEEK_API_KEY '`，长度 17 而不是 16）→ Spring 读不到 → 字面量残留 → 调用 401
+ **值带前导空格** → `Bearer sk-...`（多一个空格）→ 401

**实测**：带空格的 Key 直接调 API → `HTTP 401`；`strip()` 后 → `200 OK`。

### 5.4 前端校验不能代替后端
**前端校验是给好人的，后端校验是防坏人的。**

+ 按钮置灰只能拦住用你页面的人
+ 接口是 HTTP 接口，**curl / Postman / 脚本都能直接打**
+ 所以 `q` 为空的拦截，**后端必须自己有一份**
