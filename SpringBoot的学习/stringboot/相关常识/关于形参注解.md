**<font style="color:rgb(15, 17, 21);">前端把数据放在哪儿，后端就用哪个注解去接。</font>**

| | <font style="color:rgb(15, 17, 21);">数据位置</font> | <font style="color:rgb(15, 17, 21);">长什么样</font> | <font style="color:rgb(15, 17, 21);">用什么注解</font> |
| --- | --- | --- | --- |
| | <font style="color:rgb(15, 17, 21);">URL 路径里</font> | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">/user/delete/4</font>` | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@PathVariable</font>` |
| | <font style="color:rgb(15, 17, 21);">URL 问号后面</font> | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">/user/delete?id=4</font>` | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@RequestParam</font>` |
| | <font style="color:rgb(15, 17, 21);">请求体里</font> | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">{"id":4}</font>` | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@RequestBody</font>` |




### <font style="color:rgb(15, 17, 21);">1. </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@PathVariable</font>`<font style="color:rgb(15, 17, 21);">：数据在 URL 路径里，</font><font style="color:rgb(15, 17, 21);">这里 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">4</font>`<font style="color:rgb(15, 17, 21);"> 是路径的一部分。</font>
```java
DELETE /user/delete/4
```

<font style="color:rgb(15, 17, 21);">后端怎么写：</font>

```java
@DeleteMapping("/delete/{id}")
public String delete(@PathVariable Long id) {
    return "删除用户：" + id;
}
```

<font style="color:rgb(15, 17, 21);">Spring 看到：</font>

+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">/delete/{id}</font>`<font style="color:rgb(15, 17, 21);"> 里的 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">{id}</font>`<font style="color:rgb(15, 17, 21);"> 是占位符</font>
+ <font style="color:rgb(15, 17, 21);">实际请求是 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">/delete/4</font>`
+ <font style="color:rgb(15, 17, 21);">所以把 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">4</font>`<font style="color:rgb(15, 17, 21);"> 抠出来，赋给 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@PathVariable Long id</font>`

<font style="color:rgb(15, 17, 21);">所以方法里的 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">id</font>`<font style="color:rgb(15, 17, 21);"> 就是 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">4</font>`<font style="color:rgb(15, 17, 21);">。</font>``



### <font style="color:rgb(15, 17, 21);">2. </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@RequestParam</font>`<font style="color:rgb(15, 17, 21);">：数据在 URL 问号后面</font>
```java
DELETE /user/delete?id=4
```

<font style="color:rgb(15, 17, 21);">这里 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">id=4</font>`<font style="color:rgb(15, 17, 21);"> 在 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">?</font>`<font style="color:rgb(15, 17, 21);"> 后面，叫查询参数。</font>

<font style="color:rgb(15, 17, 21);">后端</font>

```java
@DeleteMapping("/delete")
public String delete(@RequestParam Long id) {
    return "删除用户：" + id;
}
```

<font style="color:rgb(15, 17, 21);">Spring 看到：</font>

+ <font style="color:rgb(15, 17, 21);">URL 路径是 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">/delete</font>`
+ <font style="color:rgb(15, 17, 21);">问号后面有 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">id=4</font>`
+ <font style="color:rgb(15, 17, 21);">方法参数写了 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@RequestParam Long id</font>`
+ <font style="color:rgb(15, 17, 21);">就把 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">4</font>`<font style="color:rgb(15, 17, 21);"> 赋给 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">id</font>`



### <font style="color:rgb(15, 17, 21);">3. </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@RequestBody</font>`<font style="color:rgb(15, 17, 21);">：数据在请求体里</font>
<font style="color:rgb(15, 17, 21);">请求：</font>

```java
DELETE /user/delete
Content-Type: application/json

{
  "id": 4
}
```

<font style="color:rgb(15, 17, 21);">注意：</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">{"id":4}</font>`<font style="color:rgb(15, 17, 21);"> 不在 URL 里，它在 </font>**<font style="color:rgb(15, 17, 21);">HTTP 请求体 body</font>**<font style="color:rgb(15, 17, 21);"> 里。</font>

<font style="color:rgb(15, 17, 21);">后端怎么写：</font>

```java
@DeleteMapping("/delete")
public String delete(@RequestBody DeleteUserRequest request) {
    return "删除用户：" + request.getId();
}
```

<font style="color:rgb(15, 17, 21);">Spring 看到：</font>

+ <font style="color:rgb(15, 17, 21);">方法参数有 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@RequestBody</font>`
+ <font style="color:rgb(15, 17, 21);">请求体里是 JSON，其中，</font>**<font style="color:rgba(0, 0, 0, 0.9);">前端必须在请求头声明 </font>**`**<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">Content-Type: application/json</font>**`<font style="color:rgba(0, 0, 0, 0.9);">，否则 Spring 不知道这是 JSON，直接报 </font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">415</font>`<font style="color:rgba(0, 0, 0, 0.9);">。</font>
+ <font style="color:rgb(15, 17, 21);">就用 Jackson 把 JSON 转成 Java 对象</font>
+ <font style="color:rgb(15, 17, 21);">然后传给你的方法</font>

<font style="color:rgb(15, 17, 21);"></font>

**<font style="color:rgb(15, 17, 21);">注意</font>**<font style="color:rgb(15, 17, 21);">：</font>**<font style="color:rgb(15, 17, 21);">不能同时写两个完全一样的 </font>**`**<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@DeleteMapping("/delete")</font>**`**<font style="color:rgb(15, 17, 21);">，会冲突。</font>**

**<font style="color:rgb(15, 17, 21);"></font>**

## <font style="color:rgb(15, 17, 21);">五、实际开发中怎么选？</font>
<font style="color:rgb(15, 17, 21);">虽然 DELETE 也能带请求体，但实际开发不推荐。一般这么用：</font>

| <font style="color:rgb(15, 17, 21);">场景</font> | <font style="color:rgb(15, 17, 21);">常用注解</font> | <font style="color:rgb(15, 17, 21);">例子</font> |
| --- | --- | --- |
| <font style="color:rgb(15, 17, 21);">根据 id 查详情</font> | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@PathVariable</font>` | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">GET /users/4</font>` |
| <font style="color:rgb(15, 17, 21);">分页查询</font> | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@RequestParam</font>` | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">GET /users?page=1&size=10</font>` |
| <font style="color:rgb(15, 17, 21);">新增用户</font> | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@RequestBody</font>` | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">POST /users</font>`<br/><font style="color:rgb(15, 17, 21);"> + JSON</font> |
| <font style="color:rgb(15, 17, 21);">修改用户</font> | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@PathVariable</font>`<br/><font style="color:rgb(15, 17, 21);"> + </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@RequestBody</font>` | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">PUT /users/4</font>`<br/><font style="color:rgb(15, 17, 21);"> + JSON</font> |
| <font style="color:rgb(15, 17, 21);">删除用户</font> | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@PathVariable</font>` | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">DELETE /users/4</font>` |
