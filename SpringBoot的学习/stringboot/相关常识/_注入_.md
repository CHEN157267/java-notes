**<font style="color:rgba(0, 0, 0, 0.9);">注入（Injection）= 一个对象需要的"依赖"，不由它自己 </font>**`**<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">new</font>**`**<font style="color:rgba(0, 0, 0, 0.9);">，而是由外部（Spring）造好、送进来。</font>**

**<font style="color:rgba(0, 0, 0, 0.9);">注入要拆成两个动作：</font>**

| **<font style="color:rgba(0, 0, 0, 0.9);">动作</font>** | **<font style="color:rgba(0, 0, 0, 0.9);">谁干</font>** | **<font style="color:rgba(0, 0, 0, 0.9);">是不是注入</font>** |
| --- | --- | --- |
| **<font style="color:rgba(0, 0, 0, 0.9);">创建 bean + 放进容器（池子）</font>** | <font style="color:rgba(0, 0, 0, 0.9);">Spring 容器</font> | <font style="color:rgba(0, 0, 0, 0.9);">❌</font><font style="color:rgba(0, 0, 0, 0.9);"> 这是"</font>**<font style="color:rgba(0, 0, 0, 0.9);">管理/注册</font>**<font style="color:rgba(0, 0, 0, 0.9);">"，只是把货备齐、入库</font> |
| **<font style="color:rgba(0, 0, 0, 0.9);">从池子里取出依赖，塞进目标对象</font>** | <font style="color:rgba(0, 0, 0, 0.9);">Spring 容器</font> | <font style="color:rgba(0, 0, 0, 0.9);">✅</font><font style="color:rgba(0, 0, 0, 0.9);"> 这才是"</font>**<font style="color:rgba(0, 0, 0, 0.9);">注入</font>**<font style="color:rgba(0, 0, 0, 0.9);">"</font> |


**<font style="color:rgba(0, 0, 0, 0.9);">注入 = 只指"从容器取出依赖 → 塞进需求方"这一步</font>**<font style="color:rgba(0, 0, 0, 0.9);">；"创建 bean 入池"属于容器的</font>**<font style="color:rgba(0, 0, 0, 0.9);">管理</font>**<font style="color:rgba(0, 0, 0, 0.9);">动作，不算注入。</font>**<font style="color:rgba(0, 0, 0, 0.9);">  
</font>**<font style="color:rgba(0, 0, 0, 0.9);">（整件事的大名字叫 </font>**<font style="color:rgba(0, 0, 0, 0.9);">控制反转(IoC) / 依赖注入(DI)</font>**<font style="color:rgba(0, 0, 0, 0.9);">，但狭义的"注入"动作只有送货那一下。）</font>

<font style="color:rgba(0, 0, 0, 0.9);"></font>

**<font style="color:rgba(0, 0, 0, 0.9);">IoC 是整条流水线，注入是最后一道"送货"工序。</font>**

**<font style="color:rgba(0, 0, 0, 0.9);"></font>**

## `<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Autowired</font>`<font style="color:rgba(0, 0, 0, 0.9);"> 只是"标签"，执行的是 Spring</font>
`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Autowired</font>`<font style="color:rgba(0, 0, 0, 0.9);"> </font><font style="color:rgba(0, 0, 0, 0.9);">就是贴在字段/构造上的一张</font>**<font style="color:rgba(0, 0, 0, 0.9);">声明</font>**<font style="color:rgba(0, 0, 0, 0.9);">，意思是"这里请帮我注入"。真正</font>**<font style="color:rgba(0, 0, 0, 0.9);">执行注入动作的是 Spring 容器</font>**<font style="color:rgba(0, 0, 0, 0.9);">。</font>

<font style="color:rgba(0, 0, 0, 0.9);">比喻：</font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Autowired</font>`<font style="color:rgba(0, 0, 0, 0.9);"> 是</font>**<font style="color:rgba(0, 0, 0, 0.9);">你下单</font>**<font style="color:rgba(0, 0, 0, 0.9);">，Spring 是</font>**<font style="color:rgba(0, 0, 0, 0.9);">外卖小哥</font>**<font style="color:rgba(0, 0, 0, 0.9);">。下单 ≠ 送货。</font>

<font style="color:rgba(0, 0, 0, 0.9);"></font>

**<font style="color:rgba(0, 0, 0, 0.9);">spring 造好 bean（提供方）→ 放进容器 → 谁写了 </font>**`**<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Autowired</font>**`**<font style="color:rgba(0, 0, 0, 0.9);">（需求方）就送一份给它 → 这个送货动作叫注入。</font>**
