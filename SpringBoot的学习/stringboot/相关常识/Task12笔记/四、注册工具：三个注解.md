### 4.1 `@Tool` —— 标在方法上
```plain
@Tool(description = "查询所有用户列表，返回用户名和创建时间。"
                  + "当用户问'有哪些用户''一共几个人''所有人的信息'时使用。不返回密码。")
public List<User> getUser() { ... }
```

它有两个作用，缺一不可：

| 对谁 | 作用 |
| --- | --- |
| **Spring AI** | "这个方法可以被调用" → 扫描时收进工具列表 |
| **模型** | 方法名 + description + 参数结构 → 编进请求的 `tools` 字段，成为"菜单上的菜" |


### 4.2 `@ToolParam` —— 标在参数上
```plain
public User getUserById(@ToolParam(description = "用户id") Long id)
```

没有它，模型只知道"要传一个数字"，不知道这个数字是 id 还是年龄、页码。

### 4.3 `defaultTools` —— 注册**对象**
```plain
this.chatClient = builder.defaultTools(userTools).build();   // ✅ 传对象
this.chatClient = builder.defaultTools(userTools.getUser()).build();  // ❌ 传了返回值
```

**为什么写错也编译通过**：签名是 `defaultTools(Object... toolObjects)`，**什么对象都收**。编译器不拦，运行起来工具列表却是空的。

**类型对得上 ≠ 语义对得上。** 与 `String.valueOf(null)` 返回 `"null"` 是同一类坑。

### 4.4 标在哪，就要注册哪个 —— 这是绑定的
| 标注位置 | 必须注册的对象 |
| --- | --- |
| `UserTools.getUser()` | `userTools`（这个 bean） |
| `UserServiceImpl.getUser()` | 那个 `userService` bean |


**标在 A 上、注册 B，工具列表就是空的。** 框架只在**你交给它的那个对象**里找 `@Tool`。
