1. `**<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Component</font>**`**<font style="color:rgba(0, 0, 0, 0.9);"> 那一族 → 告诉 Spring"这里要生成一个 bean"</font>**<font style="color:rgba(0, 0, 0, 0.9);"> </font><font style="color:rgba(0, 0, 0, 0.9);">✅</font>
    - `<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Service</font>`<font style="color:rgba(0, 0, 0, 0.9);"> / </font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Controller</font>`<font style="color:rgba(0, 0, 0, 0.9);"> / </font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Repository</font>`<font style="color:rgba(0, 0, 0, 0.9);"> 都是 </font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Component</font>`<font style="color:rgba(0, 0, 0, 0.9);"> 的</font>**<font style="color:rgba(0, 0, 0, 0.9);">派生注解</font>**<font style="color:rgba(0, 0, 0, 0.9);">（写在 </font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Component</font>`<font style="color:rgba(0, 0, 0, 0.9);"> 上面，等于"换了个更具体的名字"）。"类似父类"的比喻</font>**<font style="color:rgba(0, 0, 0, 0.9);">方向对</font>**<font style="color:rgba(0, 0, 0, 0.9);">，只是它们</font>**<font style="color:rgba(0, 0, 0, 0.9);">不是</font>**<font style="color:rgba(0, 0, 0, 0.9);">继承关系，叫</font>**<font style="color:rgba(0, 0, 0, 0.9);">"派生/组合"</font>**<font style="color:rgba(0, 0, 0, 0.9);">。</font>
    - <font style="color:rgba(0, 0, 0, 0.9);">功能上没差别，都是让 Spring 扫描到、创建 bean。</font>
2. `**<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Mapper</font>**`**<font style="color:rgba(0, 0, 0, 0.9);"> 那一族 → 告诉 MyBatis 搞个实现类 + 对象，交给 Spring 存进池子</font>**<font style="color:rgba(0, 0, 0, 0.9);"> </font><font style="color:rgba(0, 0, 0, 0.9);">✅</font><font style="color:rgba(0, 0, 0, 0.9);"> </font>
    - <font style="color:rgba(0, 0, 0, 0.9);">：</font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Mapper</font>`<font style="color:rgba(0, 0, 0, 0.9);"> 是 </font>**<font style="color:rgba(0, 0, 0, 0.9);">MyBatis 的</font>**<font style="color:rgba(0, 0, 0, 0.9);">注解，由 MyBatis 的扫描器处理（</font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@MapperScan</font>`<font style="color:rgba(0, 0, 0, 0.9);"> 或 </font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Mapper</font>`<font style="color:rgba(0, 0, 0, 0.9);">），不归 Spring 的 </font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Component</font>`<font style="color:rgba(0, 0, 0, 0.9);"> 扫描管线管。但</font>**<font style="color:rgba(0, 0, 0, 0.9);">结果一样</font>**<font style="color:rgba(0, 0, 0, 0.9);">——最后往 Spring 容器里注册了一个 bean。所以给 Spring 当 bean 用没错。</font>
3. `**<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Autowired</font>**`**<font style="color:rgba(0, 0, 0, 0.9);"> → 告诉 Spring"我需要符合这个条件的 bean，发一个过来"</font>**<font style="color:rgba(0, 0, 0, 0.9);"> </font><font style="color:rgba(0, 0, 0, 0.9);">✅</font><font style="color:rgba(0, 0, 0, 0.9);"></font>
    - <font style="color:rgba(0, 0, 0, 0.9);">补一个关键点：这里说的"</font>**<font style="color:rgba(0, 0, 0, 0.9);">条件</font>**<font style="color:rgba(0, 0, 0, 0.9);">"，默认是</font>**<font style="color:rgba(0, 0, 0, 0.9);">按类型（by type）匹配</font>**<font style="color:rgba(0, 0, 0, 0.9);">——找容器里类型对得上的 bean。</font>**<font style="color:rgba(0, 0, 0, 0.9);">这正是"多个实现会冲突"的原因</font>**<font style="color:rgba(0, 0, 0, 0.9);">：两个 </font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">UserService</font>`<font style="color:rgba(0, 0, 0, 0.9);"> 实现，类型都匹配，Spring 不知道选哪个，就报 </font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">NoUniqueBeanDefinitionException</font>`<font style="color:rgba(0, 0, 0, 0.9);">。你前面学的 </font>**<font style="color:rgba(0, 0, 0, 0.9);">@Primary / @Qualifier</font>**<font style="color:rgba(0, 0, 0, 0.9);">，就是用来补充这个"条件"的。</font>

<font style="color:rgba(0, 0, 0, 0.9);"></font>

<font style="color:rgba(0, 0, 0, 0.9);">关于</font>**<font style="color:rgba(0, 0, 0, 0.9);">@Primary / @Qualifier</font>**

| **<font style="color:rgba(0, 0, 0, 0.9);">注解</font>** | **<font style="color:rgba(0, 0, 0, 0.9);">贴哪</font>** | **<font style="color:rgba(0, 0, 0, 0.9);">作用</font>** | **<font style="color:rgba(0, 0, 0, 0.9);">比喻</font>** |
| --- | --- | --- | --- |
| `<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Primary</font>` | <font style="color:rgba(0, 0, 0, 0.9);">贴</font>**<font style="color:rgba(0, 0, 0, 0.9);">实现类</font>** | <font style="color:rgba(0, 0, 0, 0.9);">宣布"我是默认首选"</font> | <font style="color:rgba(0, 0, 0, 0.9);">给常用那个盖个"默认"章</font> |
| `<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Qualifier("名字")</font>` | <font style="color:rgba(0, 0, 0, 0.9);">贴</font>**<font style="color:rgba(0, 0, 0, 0.9);">注入处</font>** | <font style="color:rgba(0, 0, 0, 0.9);">当场点名"我就要这个"</font> | <font style="color:rgba(0, 0, 0, 0.9);">领料单上写清具体型号</font> |


```java
// 两个实现
@Service @Primary                                   // ← 默认选它
public class UserServiceImpl implements UserService { ... }

@Service
public class UserServiceImplCache implements UserService { ... }   // 备用

// 注入处
@Autowired
private UserService userService;                    // 没点名 → 拿 @Primary 那个

@Autowired @Qualifier("userServiceImplCache")       // ← 点名要缓存版
private UserService cacheService;

```

<font style="color:rgba(0, 0, 0, 0.9);">两个要点：</font>

1. **<font style="color:rgba(0, 0, 0, 0.9);">优先级</font>**<font style="color:rgba(0, 0, 0, 0.9);">：</font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Qualifier</font>`<font style="color:rgba(0, 0, 0, 0.9);"> </font>**<font style="color:rgba(0, 0, 0, 0.9);">比</font>**<font style="color:rgba(0, 0, 0, 0.9);"> </font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Primary</font>`<font style="color:rgba(0, 0, 0, 0.9);"> </font><font style="color:rgba(0, 0, 0, 0.9);">更具体——你当场点名了，就按点名的来；没点名，才回落到</font><font style="color:rgba(0, 0, 0, 0.9);"> </font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Primary</font>`<font style="color:rgba(0, 0, 0, 0.9);">。</font>
2. `**<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Qualifier</font>**`**<font style="color:rgba(0, 0, 0, 0.9);"> 里的名字</font>**<font style="color:rgba(0, 0, 0, 0.9);">：默认是</font>**<font style="color:rgba(0, 0, 0, 0.9);">类名首字母小写</font>**<font style="color:rgba(0, 0, 0, 0.9);">（</font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">UserServiceImplCache</font>`<font style="color:rgba(0, 0, 0, 0.9);"> → </font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">"userServiceImplCache"</font>`<font style="color:rgba(0, 0, 0, 0.9);">）。除非你在 </font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Service("xxx")</font>`<font style="color:rgba(0, 0, 0, 0.9);"> 里自己起了名。</font>

| <font style="color:rgba(0, 0, 0, 0.9);">接口（如 Mapper）</font> | <font style="color:rgba(0, 0, 0, 0.9);">MyBatis 代加工</font> | `<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Mapper</font>` |
| <font style="color:rgba(0, 0, 0, 0.9);">写个方法手工造</font> | <font style="color:rgba(0, 0, 0, 0.9);">Spring 调你的方法</font> | `<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Bean</font>`<br/><font style="color:rgba(0, 0, 0, 0.9);">（放在</font><font style="color:rgba(0, 0, 0, 0.9);"> </font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Configuration</font>`<br/><font style="color:rgba(0, 0, 0, 0.9);"> </font><font style="color:rgba(0, 0, 0, 0.9);">类里）</font> |
