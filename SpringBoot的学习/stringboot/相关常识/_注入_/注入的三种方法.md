1. **字段注入**：`@Autowired private UserMapper mapper;`（贴字段，必须写 `@Autowired`）
2. **构造注入**：依赖当构造参数（**只有一个构造器时**** **`**@Autowired**`** ****可省**）
3. **setter 注入**：贴在 setter 方法上





关于构造注入

```java
@Service
public class UserServiceImpl implements UserService {
    private final UserMapper userMapper;              // ← 这是个"需要依赖"的字段
    public UserServiceImpl(UserMapper userMapper) {    // ← 依赖作为【构造参数】
        this.userMapper = userMapper;                 // ← 塞进来 = 注入！
    }

```

**Spring 4.3+ 规定：这个类自己只有一个构造方法时，Spring 自动用它来注入，**`**@Autowired**`** 可以省略**。如果有多个构造器，那就不能省略

+ **这个类只有一个构造方法** → Spring 自动用它注入，`@Autowired` 可省。你就是这种情况。
+ **这个类有多个构造方法** → Spring 不知道用哪个，**必须**用 `@Autowired` 指定其中一个。
