1. **<font style="color:rgba(0, 0, 0, 0.9);">字段注入</font>**<font style="color:rgba(0, 0, 0, 0.9);">：</font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Autowired private UserMapper mapper;</font>`<font style="color:rgba(0, 0, 0, 0.9);">（贴字段，必须写 </font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Autowired</font>`<font style="color:rgba(0, 0, 0, 0.9);">）</font>
2. **<font style="color:rgba(0, 0, 0, 0.9);">构造注入</font>**<font style="color:rgba(0, 0, 0, 0.9);">：依赖当构造参数（</font>**<font style="color:rgba(0, 0, 0, 0.9);">只有一个构造器时</font>****<font style="color:rgba(0, 0, 0, 0.9);"> </font>**`**<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Autowired</font>**`**<font style="color:rgba(0, 0, 0, 0.9);"> </font>****<font style="color:rgba(0, 0, 0, 0.9);">可省</font>**<font style="color:rgba(0, 0, 0, 0.9);">）</font>
3. **<font style="color:rgba(0, 0, 0, 0.9);">setter 注入</font>**<font style="color:rgba(0, 0, 0, 0.9);">：贴在 setter 方法上</font>





关于构造注入

```java
@Service
public class UserServiceImpl implements UserService {
    private final UserMapper userMapper;              // ← 这是个"需要依赖"的字段
    public UserServiceImpl(UserMapper userMapper) {    // ← 依赖作为【构造参数】
        this.userMapper = userMapper;                 // ← 塞进来 = 注入！
    }

```

**<font style="color:rgba(0, 0, 0, 0.9);">Spring 4.3+ 规定：这个类自己只有一个构造方法时，Spring 自动用它来注入，</font>**`**<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Autowired</font>**`**<font style="color:rgba(0, 0, 0, 0.9);"> 可以省略</font>**<font style="color:rgba(0, 0, 0, 0.9);">。如果有多个构造器，那就不能省略</font>

+ **<font style="color:rgba(0, 0, 0, 0.9);">这个类只有一个构造方法</font>**<font style="color:rgba(0, 0, 0, 0.9);"> </font><font style="color:rgba(0, 0, 0, 0.9);">→ Spring 自动用它注入，</font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Autowired</font>`<font style="color:rgba(0, 0, 0, 0.9);"> </font><font style="color:rgba(0, 0, 0, 0.9);">可省。你就是这种情况。</font>
+ **<font style="color:rgba(0, 0, 0, 0.9);">这个类有多个构造方法</font>**<font style="color:rgba(0, 0, 0, 0.9);"> → Spring 不知道用哪个，</font>**<font style="color:rgba(0, 0, 0, 0.9);">必须</font>**<font style="color:rgba(0, 0, 0, 0.9);">用 </font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Autowired</font>`<font style="color:rgba(0, 0, 0, 0.9);"> 指定其中一个。</font>
