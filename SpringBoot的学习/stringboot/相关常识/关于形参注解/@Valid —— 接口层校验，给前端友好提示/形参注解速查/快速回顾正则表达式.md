**① 正则 = 「一个字符的规则」×「重复几次」**

****

这是组装方式，你笔记里有表但可能没连起来：

**添加到对话**

| **部位** | **写法** | **意思** |
| --- | --- | --- |
| 一个字符 | `[a-z]` | 一个小写字母 |
| | `[a-zA-Z0-9]` | 一个字母或数字 |
| | `\d`<br/> / `\w` | 一个数字 / 一个"单词字符"（字母数字下划线） |
| **重复几次** | `{6}`<br/> / `{6,}`<br/> / `{6,20}` | 正好6次 / 至少6次 / 6到20次 |


拼起来：`**[a-zA-Z0-9]{6,20}**` 念作"字母或数字，重复 6 到 20 次"。就这样，没别的。

**②**** **`**matches**`** ****是"从头到尾全匹配"，不是"包含"**

你笔记里那张用例图自己验证过：`"AB".matches("[ABC]")` 是 **false** —— 因为 `[ABC]` 只管**一个**字符。

**③ Java 字符串里的双反斜杠**

（`\\.` 的含义）。简单记：**正则里的 **`**\w**`**，写进 Java 代码要写成 **`**"\\w"**` —— 因为 Java 字符串自己也要用 `\` 转义。







规则是这样的：在方括号（字符类）里，`**_**`** ****是普通字符，直接打就行，不用转义**。真正需要当心的只有三个：

**添加到对话**

| **字符** | **什么时候会出问题** |
| --- | --- |
| `^` | 放在**第一个位置** → 意思变成"取反" |
| `-` | **夹在两个字符中间** → 变成"范围"（如 `a-z`<br/>） |
| `]` | 它是结束符本身 → 要写成 `\]` |


所以 `_` 放开头、结尾、中间都安全。你现在放开头，恰好是最不会引起歧义的位置。
