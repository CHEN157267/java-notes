| **注解** | **管什么** | **怎么用** |
| --- | --- | --- |
| `@NotNull` | 不能是 null（空串**可以**） | `@NotNull(message = "id不能为空")` |
| `@NotBlank` | **字符串**不能是 null / 空串 / 纯空格 | `@NotBlank(message = "...")` |
| `@NotEmpty` | 不能是 null **且**长度 > 0（用于集合、字符串） | `@NotEmpty` |
| `@Size(min=,max=)` | **长度**范围（字符串/集合） | `@Size(min = 6, max = 20)` |
| `@Min(0)`<br/> / `@Max(100)` | 数值范围 | `@Min(value = 0, message = "...")` |
| `@Pattern(regexp=)` | 正则匹配 | `@Pattern(regexp = "^[a-zA-Z0-9]+$")` |


Bean Validation 里，除了 @NotNull / @NotEmpty / @NotBlank 这三个，其它所有约束注解遇到 null 都当作"通过"。



通常的做法是再配一个非空注解（@NotBlank），两道关卡各管一段：一个有值、一个符合格式 —— 正好是你笔记里"注解只管一件事"



@Pattern 用的是全匹配语义（等同 String.matches()）
