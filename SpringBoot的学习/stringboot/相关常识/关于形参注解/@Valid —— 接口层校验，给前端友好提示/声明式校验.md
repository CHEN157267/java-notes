## `<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@NotBlank</font>`<font style="color:rgba(0, 0, 0, 0.9);"> / </font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Size</font>`**<font style="color:rgba(0, 0, 0, 0.9);">光把注解标在字段上不会生效</font>**<font style="color:rgba(0, 0, 0, 0.9);">——它只是一张"规则清单"，得有东西去</font>**<font style="color:rgba(0, 0, 0, 0.9);">执行</font>**<font style="color:rgba(0, 0, 0, 0.9);">它。执行者是 </font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Valid</font>`<font style="color:rgba(0, 0, 0, 0.9);">：</font>
```java
// 规则写在实体字段上（你写的这两句 ✅）
public class User {
    @NotBlank(message = "用户名不能为空")
    @Size(min = 3, max = 20, message = "用户名长度需在 3-20 之间")
    private String username;
}

// 但要在这里"启用"它才真的跑
@PostMapping("/add")
public String add(@Valid @RequestBody User user) { ... }
//                ↑↑↑↑↑↑ 这个开关

```

**<font style="color:rgba(0, 0, 0, 0.9);">没有 </font>**`**<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">@Valid</font>**`**<font style="color:rgba(0, 0, 0, 0.9);">，注解就是墙上的装饰</font>**<font style="color:rgba(0, 0, 0, 0.9);">。</font>
