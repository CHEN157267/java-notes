## 二、三个坑（每题 8 分）
**Q5.** 下面三个场景分别对应"穿透 / 击穿 / 雪崩"里的哪一个？说明判断依据。

+ A. 攻击者用随机 id 疯狂请求 `/user/999xxx`，这些 id 在库里都不存在
