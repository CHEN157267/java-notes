| **码** | **含义** | **出现在** |
| --- | --- | --- |
| `0` | 成功 | add / update / delete |
| `-1` | id 不存在 | update / delete |
| `-2` | 用户名已存在 | **add / update** |
| `1` | 意外失败 | add / update |
