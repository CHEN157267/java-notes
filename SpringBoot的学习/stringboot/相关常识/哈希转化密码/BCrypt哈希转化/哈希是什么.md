### 存密码（注册 / 改密码）
```plain
明文  →  encoder.encode(明文)
           └→ 随机生成【新】盐 → 算 → "$2a$10$新盐 + 哈希"（60 字符）
库    ←  直接存字符串（数据库根本不知道那是密码）
```

对应代码：`UserServiceImpl.addUser` 第 28 行 / `updateUser` 第 42 行

### 验密码（登录）
```plain
输入明文 + 库里那串
     ↓  BCrypt.matches(明文, 密文)
     ① 从密文里【读出】当年那个盐（不重新生成！）
     ② 用这个盐 + 明文重算一遍
     ③ 逐字符比对
```

+ **不还原，只重算。** 哈希的验证从来不是"解回原文"，而是"**用同一套参数再算一次，看结果对不对得上**"

★ **随机只发生在「第一次生成」那一刻**，之后被冻进密文里，每次校验读的是同一个。 类比：**铸币的印章** —— 刻章时图案随机，之后每枚硬币都盖同一个章，所以能验真伪。

★ **盐永远从库里「读」，从不往输入里「写」。** 用户输入里**根本没有盐**，一根毛都没有。
