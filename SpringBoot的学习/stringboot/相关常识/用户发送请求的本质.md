**<font style="color:rgba(0, 0, 0, 0.44);">现实里用户是点删除按钮，前端把数据传给后端，怎么会是 /delete/{id} 这个网址？</font>**

**<font style="color:rgba(0, 0, 0, 0.86);">答案：前端点按钮之后，它背后发的就是那个网址的请求。</font>**

<font style="color:rgba(0, 0, 0, 0.86);">看完整链路（假设用户要删 id=4 的用户）：</font>

```plain
① 用户视角：看到一行用户数据，点了一下"删除"按钮
        ↓
② 前端代码：按钮早就绑定了这行的id=4，JS执行：
        axios.delete('/user/delete/4')     ← 这个URL是前端代码自己拼的！
        ↓
③ 网络传输：浏览器发出请求  DELETE /user/delete/4
        ↓
④ 后端接收：@DeleteMapping("/delete/{id}") 接住，@PathVariable 取出 4
        ↓
⑤ 数据库：删掉 id=4 这条记录
        ↓
⑥ 前端收到结果：把那一行从页面上抹掉
```

**<font style="color:rgba(0, 0, 0, 0.86);">键澄清</font>**<font style="color:rgba(0, 0, 0, 0.86);">：</font>

+ `**<font style="color:rgba(0, 0, 0, 0.86);">/delete/{id}</font>**`**<font style="color:rgba(0, 0, 0, 0.86);"> </font>****<font style="color:rgba(0, 0, 0, 0.86);">不是给用户敲门用的地址，是"前后端约定的接口格式"</font>**
+ <font style="color:rgba(0, 0, 0, 0.86);">用户永远看不到这个URL，也永远不用输入它——</font>**<font style="color:rgba(0, 0, 0, 0.86);">是前端代码按这个格式发请求</font>**
+ <font style="color:rgba(0, 0, 0, 0.86);">"输入id"这件事发生在</font>**<font style="color:rgba(0, 0, 0, 0.86);">页面交互</font>**<font style="color:rgba(0, 0, 0, 0.86);">上（点哪一行、或在输入框填id），前端拿到了id，再拼进URL发给后端</font>

<font style="color:rgba(0, 0, 0, 0.86);"></font>

| <font style="color:rgba(0, 0, 0, 0.86);">写法</font> | <font style="color:rgba(0, 0, 0, 0.86);">请求长啥样</font> | <font style="color:rgba(0, 0, 0, 0.86);">后端接收</font> |
| --- | --- | --- |
| <font style="color:rgba(0, 0, 0, 0.86);">A 路径参数</font> | `<font style="color:rgba(0, 0, 0, 0.86);">DELETE /user/delete/4</font>` | `<font style="color:rgba(0, 0, 0, 0.86);">@PathVariable</font>` |
| <font style="color:rgba(0, 0, 0, 0.86);">B 查询参数（你现在用的）</font> | `<font style="color:rgba(0, 0, 0, 0.86);">DELETE /user/delete?id=4</font>` | `<font style="color:rgba(0, 0, 0, 0.86);">@RequestParam</font>` |
| <font style="color:rgba(0, 0, 0, 0.86);">C 请求体</font> | `<font style="color:rgba(0, 0, 0, 0.86);">DELETE /user/delete</font>`<br/><font style="color:rgba(0, 0, 0, 0.86);"> + body </font>`<font style="color:rgba(0, 0, 0, 0.86);">{"id":4}</font>` | `<font style="color:rgba(0, 0, 0, 0.86);">@RequestBody</font>` |
