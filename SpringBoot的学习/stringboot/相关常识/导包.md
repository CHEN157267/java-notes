**第一，看包名第一段**：

| **前缀** | **是谁** |
| --- | --- |
| `org.springframework.*` | Spring 框架 |
| `org.slf4j.*` | 日志 |
| `org.mybatis.*` | MyBatis |
| `com.example.demo.*` | 你自己写的 |


**第二，记一个默认答案**：

**Spring Boot 项目里，**`**Logger**`** ****几乎永远是**** **`**org.slf4j.Logger**`**。**

这一条能覆盖你 99% 的导包场景。**记住"标准答案"，比临场分辨快得多。**

**已经导错了怎么办**：不用删那行重来——光标放到**标红的类名**上，按 `Alt+Enter`，会列出所有同名候选，选包名对的那个。IDEA 有这个"换一个 import"的动作。
