## 这个 Task 做了什么（速览）
给 `/ai/chat` 接上「能查数据库」的能力：用户问“id 为 4 的用户是谁”，模型不再说“我不知道”，而是**输出一段调用意图**，由我们的代码执行查询，再把结果交回模型组织回答。

| 做了什么 | 关键点 |
| --- | --- |
| 新建 `agent/UserTools`（`@Component`） | 两个只读方法，标 `@Tool` |
| `AiServiceImpl` 注册 | `builder.defaultTools(userTools)` —— 传**对象** |
| `UserService` 加 `getUserById` | 用 `selectById`，查不到返回 `null` |
| 两个工具各打一条日志 | 工具名 + 参数 + 结果 + 耗时 |
| 写操作一律不标 `@Tool` | 安全边界，不是"暂时不做" |






## ★ 错题清单（重点）
### 1. 把"没有执行能力"说成"权限不够"
| ❌ 我的说法 | ✅ 准确说法 |
| --- | --- |
| "模型只有部分权限，只看到指定的方法" | **模型没有执行通道**，就算给它全部方法，它还是只能输出 JSON |


**为什么重要**：说"权限"会让人以为"给它更高权限它就能执行" —— 而真相是**它永远不能执行**。

### 2. 参数"是用户发来的"，没说"抽取"
用户原话里**没有 **`**id=4**`** 这个字段**，只有中文。模型做的是从自然语言里**抽取**`4` 并判断它属于 `id`。

**漏掉"抽取"，就漏掉了这是模型的主动判断** —— 也就理解不了它为什么会抽错。

### 3. 讲"为什么不能注册写操作"时，漏了"没有人工确认"
"会影响类纯粹度""耦合"都对，但那些是**设计问题**。最硬的一条是：

**写操作执行了就没有确认环节，也没有撤销。**

而且参数是模型填的，可能填错 —— **你连拦的机会都没有**。

### 4. 把"耦合"当成了"爆炸半径"
| 概念 | 指什么 |
| --- | --- |
| **耦合** | 改这里会不会牵连那里（设计层面） |
| **爆炸半径** | 错一下能毁多大范围、能不能救回来（故障层面） |


两个都要防，但不是一回事。

### 5. `description` 里混进了"写作说明"
把"并且注明""当用户问 X 时用这个"这种**指导自己写作**的话抄进了 description。

**判据**：念出来像不像在跟模型介绍？不像就是没转过来。

### 6. `defaultTools` 传了方法返回值（代码）
```plain
builder.defaultTools(userTools.getUser())   // ❌ 这是 List<User>
builder.defaultTools(userTools)             // ✅ 对象
```

**为什么编译能过**：形参是 `Object...`。**类型对得上，语义对不上** —— 运行期工具表是空的。

### 7. `if` 忘写 `else`（老毛病复发）
```plain
builder.defaultTools(userTools.getUser())   // ❌ 这是 List<User>
builder.defaultTools(userTools)             // ✅ 对象
```

**根因**：心里以为"if 走完就 return 了"，但 return 在方法末尾。

**防线**：这类 bug 跑一次就能看出来 —— **写完必须跑，日志是证据**。

## 十二、速记表
| 概念 | 一句话 |
| --- | --- |
| **本质** | 模型有判断力，没有执行能力 |
| **菜单** | 每次请求由我们把工具清单塞进去，不是模型自己去看 |
| **执行** | `ToolCallingManager` 用反射调你的方法 |
| **三段 messages** | USER（用户）/ ASSISTANT（模型）/ TOOL（我们执行的结果） |
| **为什么要带前两段** | 模型没有记忆，每轮都是全新开始 |
| **参数** | 模型从自然语言里**抽取**并填入 |
| **绑定关系** | 标在哪，就必须注册哪个对象 |
| **扫描范围** | ORM 扫全项目；Tool 只扫你交的那个对象 |
| **安全边界** | 写操作一律不注册 —— 查错是答非所问，写错是数据没了 |
| **description** | 干什么 / 什么时候用 / 边界在哪；**别混进写作说明** |
| **日志格式** | `[工具] 名称 参数 -> 结果 耗时` |
| **环境坑** | curl 通但 Java 不通 → 先查 IPv6，再查系统代理 |
