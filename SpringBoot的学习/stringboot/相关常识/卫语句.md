**核心一句：if 里面已经 return 了，后面的代码只有"条件不成立"才会执行到 —— 所以 **`**else**`** 是多余的。**

改法是反过来问：不是"存在吗？存在我就做点什么"，而是"**不存在？那我立刻走人**"。

```java
if (!(userMapper.exists(...))) return -1;   // 不满足就早退
if (查重命中)                  return -2;
if (userMapper.updateById(user) > 0) return 0;
return 1;
```

好处：**主流程不缩进**，读的人不用同时在脑子里记住好几个条件。
