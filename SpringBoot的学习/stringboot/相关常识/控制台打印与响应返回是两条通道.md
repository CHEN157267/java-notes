## <font style="color:rgba(0, 0, 0, 0.9);">就地报错、带原因"该怎么写？—— 三条路，你想要的在第二条</font>
<font style="color:rgba(0, 0, 0, 0.9);">你的诉求是：</font>**<font style="color:rgba(0, 0, 0, 0.9);">校验点就在那里，我想当场中断，并且把原因带出去。</font>**<font style="color:rgba(0, 0, 0, 0.9);"> 正解是</font>**<font style="color:rgba(0, 0, 0, 0.9);">抛异常</font>**<font style="color:rgba(0, 0, 0, 0.9);">，不是打印：</font>

```java
// ① 你已经会了：就地 return（短路）
if (count != 0L) { return "username already exists"; }

// ② 更专业的做法：就地"抛"出去
if (count != 0L) { throw new RuntimeException("用户名已存在"); }
//                ↑ 方法在这里立即中断，异常往上飞

```

`**<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">throw</font>**`**<font style="color:rgba(0, 0, 0, 0.9);"> </font>****<font style="color:rgba(0, 0, 0, 0.9);">和</font>****<font style="color:rgba(0, 0, 0, 0.9);"> </font>**`**<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">return</font>**`**<font style="color:rgba(0, 0, 0, 0.9);"> </font>****<font style="color:rgba(0, 0, 0, 0.9);">的共同点</font>**<font style="color:rgba(0, 0, 0, 0.9);">：都会</font>**<font style="color:rgba(0, 0, 0, 0.9);">立刻中断</font>**<font style="color:rgba(0, 0, 0, 0.9);">当前方法（所以"就地报错"这个需求满足了）。  
</font>**<font style="color:rgba(0, 0, 0, 0.9);">区别</font>**<font style="color:rgba(0, 0, 0, 0.9);">：</font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">return</font>`<font style="color:rgba(0, 0, 0, 0.9);"> </font><font style="color:rgba(0, 0, 0, 0.9);">是把信息</font>**<font style="color:rgba(0, 0, 0, 0.9);">交给调用者</font>**<font style="color:rgba(0, 0, 0, 0.9);">（层层往上 return）；</font>`<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">throw</font>`<font style="color:rgba(0, 0, 0, 0.9);"> </font><font style="color:rgba(0, 0, 0, 0.9);">是把信息</font>**<font style="color:rgba(0, 0, 0, 0.9);">甩给异常处理机制</font>**<font style="color:rgba(0, 0, 0, 0.9);">。</font>

<font style="color:rgba(0, 0, 0, 0.9);">第 ② 种为什么更专业？因为</font>**<font style="color:rgba(0, 0, 0, 0.9);">异常能带更多东西</font>**<font style="color:rgba(0, 0, 0, 0.9);">：错误码、异常类型（是"参数错"还是"业务错"还是"系统错"）、甚至多个字段的校验结果。前端拿到之后就能</font>**<font style="color:rgba(0, 0, 0, 0.9);">根据错误码分类处理</font>**<font style="color:rgba(0, 0, 0, 0.9);">（弹提示 / 跳登录页 / 显示 toast）。</font>

**<font style="color:rgba(0, 0, 0, 0.9);">但 </font>**`**<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.05);">throw</font>**`**<font style="color:rgba(0, 0, 0, 0.9);"> 有个问题</font>**<font style="color:rgba(0, 0, 0, 0.9);">：没人接的话，Spring 就给你甩一个 500（你上次缺 password 时见过）。所以需要有人</font>**<font style="color:rgba(0, 0, 0, 0.9);">统一接住</font>**<font style="color:rgba(0, 0, 0, 0.9);">它</font>
