```java
int result = userMapper.updateById(user);
return "update success,new id =" + result;   // ❌ 这里说错了
```

`pdateById` / `deleteById` 返回的 `int` **不是id，是"这次操作影响了几行数据"**

| **情况** | **result 的值** |
| --- | --- |
| **成功修改/删除了 1 条** | `**1**` |
| **传入的 id 在数据库里****不存在** | `**0**` |
