| **方法** | **对应 SQL** | **用途** |
| --- | --- | --- |
| `eq`<br/> / `ne` | `=`<br/> / `<>` | 等于 / 不等于 |
| `like` | `LIKE '%x%'` | 模糊查 |
| `gt`<br/> / `ge`<br/> / `lt`<br/> / `le` | `>`<br/> / `>=`<br/> / `<`<br/> / `<=` | 大小比较 |
| `in`<br/> / `between` | `IN`<br/> / `BETWEEN` | 集合 / 区间 |
| `isNull` | `IS NULL` | 判空 |
| `orderByDesc`<br/> / `orderByAsc` | `ORDER BY … DESC/ASC` | 排序 |


⚠️ **多个条件默认用 **`**AND**`** 连接**。想用 `OR` 要显式写 `.or()`，这个以后遇到再说。
