```java
浏览器请求
    ↓
Controller 层（@RestController）：接收请求，调用 Service
    ↓
Service 层（@Service）：业务逻辑，调用 Repository
    ↓
Repository 层（@Repository）：操作数据库
    ↓
返回结果原路返回：Repository → Service → Controller → 浏览器
```

| <font style="color:rgb(15, 17, 21);">层</font> | <font style="color:rgb(15, 17, 21);">注解</font> | <font style="color:rgb(15, 17, 21);">职责</font> |
| --- | --- | --- |
| <font style="color:rgb(15, 17, 21);">Controller</font> | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@RestController</font>`<br/><font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">/</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@Controller</font>` | <font style="color:rgb(15, 17, 21);">接收请求，调用 Service，返回响应</font> |
| <font style="color:rgb(15, 17, 21);">Service</font> | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@Service</font>` | <font style="color:rgb(15, 17, 21);">业务逻辑（如注册时检查用户名是否已存在）</font> |
| <font style="color:rgb(15, 17, 21);">Repository</font> | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@Repository</font>` | <font style="color:rgb(15, 17, 21);">操作数据库（增删改查）</font> |


**<font style="color:rgb(15, 17, 21);">调用链：Controller → Service → Repository → 数据库</font>**

<font style="color:rgb(15, 17, 21);">Controller 注入 Service，Service 需要数据库操作时再注入 Repository。  
</font><font style="color:rgb(15, 17, 21);">不是所有请求都涉及数据库，但大多数业务功能都离不开。</font>
